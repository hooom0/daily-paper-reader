## 摘要
提升文本到图像模型传统上依赖于增大模型规模或增加去噪步数。在本工作中，我们探索了一种扩展计算的替代方式：在每个去噪步内重复运行共享的Transformer块，从而在保持参数量不变的同时有效增加计算深度。这种循环计算能够在没有显式推理token的情况下对内部表示进行迭代精炼。然而，朴素循环并不能持续提升图像质量。我们将该问题归因于中间循环之间的监督较弱，以及不受调控的注意力更新会逐步侵蚀局部信息。为克服这些挑战，我们提出了循环扩散Transformer（Looped-DiT），它将中间循环间的深度监督与自调制注意力相结合，以稳定循环特征更新。在参数量匹配和计算量匹配的设置下，Looped-DiT始终优于非循环基线。值得注意的是，一个2.6亿参数的循环模型在多个文本到图像基准上能够超越参数量为其6.5倍的模型，同时所需推理计算量仅约为后者的1/4.9。除了这一性能提升，我们发现循环计算可以为扩散模型提供一种更有效的迭代计算形式：在固定推理预算下，增加循环深度比增加去噪步数带来更大收益。此外，更深的循环能够逐步纠正先前循环中所犯的错误，表现出类似潜在推理的行为。这些结果共同表明，循环计算为扩展视觉生成模型提供了一条有前景的途径。

## Abstract
Improving text-to-image models has traditionally relied on increasing model size or the number of denoising steps. In this work, we explore an alternative way to scale computation by repeatedly running shared Transformer blocks within each denoising step, effectively increasing computational depth while keeping the parameter count fixed. This looped computation enables iterative refinement of internal representations without explicit reasoning tokens. However, naive looping fails to consistently improve image quality. We trace this problem to weak supervision across intermediate loops and unregulated attention updates that progressively erode local information. To overcome these challenges, we propose Looped Diffusion Transformer (Looped-DiT), which combines deep supervision across intermediate loops with self-modulating attention to stabilize looped feature updates. Under matched-parameter and matched-compute settings, Looped-DiT consistently outperforms non-looped baselines. Notably, a 260M-parameter looped model can surpass a model 6.5x larger across multiple text-to-image benchmarks while requiring 4.9x lower inference compute. Beyond this performance gain, we find that looped computation can offer a more effective form of iterative computation for diffusion models, with increasing loop depth yielding larger gains than adding more denoising steps under a fixed inference budget. Furthermore, deeper loops can progressively correct mistakes made in earlier loops, exhibiting behaviors suggestive of latent reasoning. Together, these results show that looped computation offers a promising way to scale visual generation models.

# Looped Diffusion Transformer 论文总结

## 1. 核心问题与整体含义
- **研究动机**：提升文本到图像（T2I）生成模型通常依赖增大参数量或增加去噪步数，但二者都会显著提高训练与推理成本。
- **替代思路**：在每个去噪步内重复运行共享 Transformer 块，即“循环计算”，在不增加参数量的前提下增加有效计算深度。
- **关键矛盾**：朴素循环并不能稳定提升图像质量。浅层循环可能低于非循环基线，循环加深后性能饱和甚至下降；同时空间信息逐步丢失，位置探针 R² 从第 1 次循环的 0.865 降至第 8 次的 0.562。
- **整体含义**：论文首次系统研究 T2I 生成中的循环计算，探索其能否提升参数效率、更有效利用推理计算，并支持无需显式文本推理链的“潜在视觉推理”。

## 2. 方法论
### 2.1 核心思想
- 基于 MiniT2I / MMDiT 架构，将 17 个 Transformer 块划分为前循环 A、循环 B、后循环 C 三组，默认拆分为 [6, 5, 6]。
- 在每个去噪步内，A 和 C 各运行一次，中间 5 个共享块 B 重复 N 次，参数跨循环共享。
- 前向流程可概括为：  
  \(h^{(0)}=A(h_{\text{input}})\)，\(h^{(r)}=B(h^{(r-1)})\)，\(\hat{x}_0=C(h^{(N)})\)。  
  其中 N 为循环深度，增加 N 增加计算深度但不增加参数量。

### 2.2 深监督（Deep Supervision）
- 仅监督最终循环会导致早期循环状态缺少直接学习信号，优化路径过长。
- 对每个循环深度 n，将中间隐藏状态通过共享的后循环阶段 C 解码，得到 \(\hat{x}^{(n)}_0\)。
- 所有循环预测共享同一噪声输入和时间步，并对同一干净图像 \(x_0\) 计算流匹配损失：
  \(\ell_n = E[\|\hat{x}^{(n)}_0-x_0\|_2^2 / d_x c(t)^2]\)。
- 总损失为各循环损失的加权和：\(L=\sum_{n=1}^N w_n \ell_n\)。
- 论文比较了两种权重：指数权重 (1/8, 1/4, 1/2, 1) 与 Final+Mean 权重 (1/3, 1/3, 1/3, 1)，最终采用 Final+Mean。
- 深监督仅用于训练，不引入额外参数或推理开销。

### 2.3 自调制注意力（Self-Modulating Attention）
- 仅应用于循环块 B，用于抑制重复注意力更新对图像 token 表示的过度覆盖。
- 包含两种实现：
  - **Gated Attention**：对每个注意力头输出乘以 token 相关的可学习标量门 \(G=\sigma(w^\top u+b)\)，显式控制更新强度。
  - **Exclusive Self Attention（XSA）**：参数免费，用投影 \(G=I-\hat{v}\hat{v}^\top\) 去除注意力输出中沿 token 自身 value 方向的分量，从而消除自 value 项并抑制过度写入。
- 两者都在注意力输出写回残差流之前进行调制，且每轮循环根据当前隐藏状态重新计算。
- 还提出可选的自适应循环：用轻量门控网络预测继续循环的收益，按阈值 λ 决定是否提前退出。
