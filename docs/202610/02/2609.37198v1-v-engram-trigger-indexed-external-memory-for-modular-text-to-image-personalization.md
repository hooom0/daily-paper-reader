## 摘要
预训练的文本到图像模型包含广泛的视觉知识，但它们无法在仅凭少量参考图像的情况下可靠地获取或细化特定视觉身份，同时保持组合控制。Token 嵌入方法紧凑，但往往对身份拟合不足；而基于适配器的方法通过持久权重更新提升保真度，但这些更新存储成本高，且在概念组合时可能相互干扰。我们提出 V-Engram，一种面向 Stable Diffusion 3.5 的触发索引外部记忆机制。每个概念被分配一个显式触发器，用于检索概念特定的记忆；该记忆的门控方向以相对残差的形式进入冻结的文本编码器和 MMDiT 上下文状态。将这种记忆与骨干网络适配分离，使得无需合并模型更新即可实现提示选择性和多概念访问。实验表明，V-Engram 在整体主体保真度上大致与 DreamBooth-LoRA 相当，同时在上下文主体保持等设置中显示出优势。提示匹配加载仅检索匹配的条目，从而为单概念查询减少大部分额外的适配状态加载。定性结果进一步展示了配对触发器组合和同类分离，而未注册条目的提示则保留冻结模型的基础行为。总之，这些结果确立了触发索引记忆作为一种模块化接口，能够在不重写生成器的情况下添加有针对性的视觉证据。

## Abstract
Pretrained text-to-image models contain broad visual knowledge, yet they cannot reliably acquire or refine a specific visual identity from only a few references while preserving compositional control. Token-embedding methods are compact but often underfit identity, whereas adapter-based methods improve fidelity through persistent weight updates that can be costly to store and interfere when concepts are composed. We introduce V-Engram, a trigger-indexed external memory mechanism for Stable Diffusion 3.5. Each concept is assigned an explicit trigger that retrieves concept-specific memory, whose gated directions enter frozen text-encoder and MMDiT context states as relative residuals. Separating this memory from backbone adaptation enables prompt-selective and multi-concept access without merging model updates. Experiments show that V-Engram broadly matches DreamBooth-LoRA in overall subject fidelity while showing advantages in settings such as contextual subject preservation. Prompt-matched loading retrieves only matched entries, reducing most additional adaptation-state loading for a single-concept query. Qualitative results further demonstrate paired-trigger composition and same-class separation, while prompts without registered entries retain the frozen model's base behavior. Together, these results establish trigger-indexed memory as a modular interface for adding targeted visual evidence without rewriting the generator.

  - **参考编码类**（IP-Adapter、PhotoMaker、InstantID 等）：推理时依赖参考图编码器，个性化接口中包含参考图。
- **核心追问**：定向视觉证据应存于何处？提示如何检索它？如何在不覆盖有用先验的前提下进入生成过程？
- **针对架构的特殊性**：Stable Diffusion 3.5 的 MMDiT 中文本与图像 token 全程交互，而非固定 U-Net 交叉注意力接口，因此需要新的注入位置设计。
- **总体含义**：论文提出把"概念记忆"与"骨干适配"解耦，以**精确触发索引的外部记忆**作为模块化接口，在不重写生成器的前提下按提示选择性地注入视觉证据。

## 2. 方法论

### 2.1 核心思想
- 为每个概念分配显式触发器（如 `<dog>`），在冻结的 SD3.5 上建立**触发索引外部记忆**；记忆由可训练的"方向向量 + 门控"组成，以**门控相对残差**形式注入冻结的文本编码器与 MMDiT 上下文状态。

### 2.2 触发索引记忆注册表
- SD3.5 含三个 tokenizer 流：CLIP-L、OpenCLIP-G、T5-XXL（记作集合 G）；同一触发器在不同流中分词不同，故**每个 tokenizer 建独立注册表**。
- 精确 token-id 扫描：`A_g(p) = {(m,i) : τ_g(p)_{i:i+|κ_m|} = κ_m, κ_m ∈ R_g}`，即匹配注册跨度 κ_m 及其起始位置。
- 主配置注册**连续 2–4-gram**，并始终保留完整触发跨度；单 token 触发器用精确跨度。所有精确匹配（含重叠）全部激活并求和。
- 检索基于 token id 的**确定性词法寻址**，不使用语义/近似检索、注意力检测或提示改写；无匹配时条件路径等同冻结基模型。

### 2.3 门控相对残差注入
- 每个注册条目 m 与挂载点 `q=(g,ℓ)` 存储：可训练方向 `e_{m,q} ∈ R^{d_q}` 与逐通道门 `a_{m,q} ∈ R^{d_q}`。
- 残差形式：`Δ_{m,q}(H_q) = ρ(H_q) · ( e_{m,q}/‖e_{m,q}‖₂ + ε ⊙ tanh(a_{m,q}) )`，其中 `ρ(H_q) = sg( (1/T_q) Σ_j ‖H_q,j‖₂ )` 为**分离梯度**的隐状态平均范数。
- 三项分工：方向向量给残差方向；tanh 门提供有界、可正负的逐通道调制；detached 范数按当前激活尺度做相对缩放（避免朴素加法记忆过度扰动冻结隐状态）。
- 对照基线（直接嵌入）：`Δ^ungated_{m,q} = e_{m,q}`，无门控、无方向归一化、无相对缩放。
- 注入更新：`H̃_{q,j} = H_{q,j} + Σ_{m ∈ C_{q,j}(p)} Δ_{m,q}`，C 为覆盖位置 j 的所有匹配条目；可同时处理完整触发跨度与一个触发器激活多个 n-gram 条目的情形。

### 2.4 在 SD3.5 中的挂载
- 三个文本编码器流均挂载；CLIP-L / OpenCLIP-G 挂在**倒数第二个 transformer block 之前**，T5-XXL 挂在**最后一个 encoder block 之前**。
- MMDiT 的 text/context block 中选择性挂载，默认 **7 个均匀分布 block**：`{0, 6, 12, 19, 25, 31, 37}`。
- 拼接上下文时保留 tokenizer 特定偏移，使 CLIP 匹配只注入 CLIP 区域、T5 匹配只注入 T5 区域；pooled projection 路径保持不变。

### 2.5 训练目标与存储
- 全部预训练组件冻结，仅更新 Engram 方向与门。
- Rectified flow 目标：`z_t = (1−t)z_0 + tε`，`v = ε − z_0`，`L_flow = E‖F_θ(z_t, t, p; φ_{A(p)}) − v‖₂²`，其中 A(p) 为三个流中提示匹配到的活跃条目并集。
- 存储规模：`|φ_c|_params = 2 Σ_{q∈Q} K_{c,g(q)} d_q`（方向 + 门各一份）；ungated 变体仅存嵌入向量，约为一半。
- 推理时仅激活提示匹配条目，多概念通过匹配多个触发器并求和残差组合，**不合并 LoRA、不修改骨干权重**。

## 3. 实验设计

- **数据集 / 场景**：
  - 主基准：**15 个主体、80 张 Google DreamBooth 参考图**。
  - 同类消歧：**7 只狗、37 张参考图**（同数据集）。
  - 熟悉身份精修：**15 个 Celebrity-1000 身份**，每人 5 张训练图 + 5 张图像不重叠测试图（姿态、发型、光照、场景明显变化）。
- **对比方法**：
  - 冻结的 zero-shot SD3.5；
  - TI 风格嵌入学习；
  - 联合 DreamBooth-LoRA（rank 4 = 5.895M 参数为受控配置；rank 8 = 11.790M 作为接近 V-Engram 全注册表 10.477M 的容量对照）；
  - V-Engram。
- **训练设置**：所有学习型方法共用相同参考图与 15 主体联合训练；TI 25k 步（lr 1e-3）、LoRA 8k 步（lr 1e-4）、V-Engram 20k 步（lr 5e-4）；batch 4、AdamW、常数调度、bfloat16、seed 42。
- **推理与指标**：主比较使用 "a photo of `<trigger>`"，seeds 42–46 各出 5 张 768×768 图，20 步、guidance 4.5、默认调度器、无负提示、bfloat16。指标为 CLIP-I、DINOv2（best-ref 与 all-pairs 两种聚合）、CLIP-T；身份任务用 InsightFace `buffalo_l` 的 ArcFace 风格人脸嵌入，仅与留出参考比较，并单独报告有效人脸覆盖率。
- **消融 / 分析实验**：
  - 挂载密度：encoder-only vs N=3–9 个 MMDiT block（5 概念、28 参考、10k 步、每概念 5 seed）。
  - 门控残差 vs TI 式直接单向量注入（同数据、调度、挂载点）。
  - 上下文组合：5 个类别无关模板（特写、房间、雪地、花园、红车旁），15 主体 × 5 模板 = 每方法 75 张。
  - 未触发基础行为保持：8 个普通类别 × 7 模板 = 56 条无注册触发器提示。
  - 多概念组合：20 组配对触发提示（定性）。
  - 同类消歧：7 只狗，索引式与命名式触发器，3 种提示场景。
  - 熟悉身份精修：15 身份 × 5 图。
