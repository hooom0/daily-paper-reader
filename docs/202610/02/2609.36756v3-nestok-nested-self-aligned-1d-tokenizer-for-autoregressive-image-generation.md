## 摘要
一维（1D）可变长度视觉分词器通过改变 token 数量实现自适应压缩，使下游自回归（AR）模型能够使用单个分词器灵活权衡生成质量与计算成本。然而，现有基于嵌套 dropout 的方法往往未能充分利用分词器的表示能力，导致在图像重建和生成方面性能欠佳。在这项工作中，我们提出了 NesTok，一个为动态视觉分词器量身定制的嵌套自对齐框架。NesTok 引入了跨长度训练，在联合优化不同 token 长度下的重建的同时，使用全长序列指导较短序列，使较短的 token 序列能够接近全长序列的重建质量。在 ImageNet 上，NesTok 相比标准训练有显著提升，并取得了 0.98 的 rFID 分数。在下游图像生成任务中，在现有的可变长度自回归图像生成方法中，它在 ImageNet 256×256 上取得了 1.46 的最先进 gFID 分数。代码将发布于 https://github.com/Jiawei804/NesTok。

## Abstract
One-dimensional (1D) variable-length visual tokenizers enable adaptive compression by varying the number of tokens, allowing downstream autoregressive (AR) models to flexibly trade off generation quality against computational cost using a single tokenizer. However, existing approaches based on nested dropout often fail to fully exploit the representational capacity of the tokenizer, resulting in suboptimal performance in both image reconstruction and generation. In this work, we introduce NesTok, a nested self-alignment framework tailored to dynamic visual tokenizers. NesTok introduces cross-length training, which jointly optimizes reconstruction across token lengths while using the full-length sequence to guide shorter counterparts, enabling shorter token sequences to approach the reconstruction quality of full-length sequences. On ImageNet, NesTok improves substantially over standard training and achieves an rFID score of 0.98. On downstream image generation, it achieves the state-of-the-art gFID score of 1.46 on ImageNet 256$\times$256 among existing variable-length autoregressive image generation methods. Code will be available at https://github.com/Jiawei804/NesTok.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：图像生成在扩散模型与自回归（AR）范式下均取得显著进展，视觉分词器（visual tokenizer）是其中的关键组件。近年一维（1D）分词器因能以更高压缩比保留重建保真度、更接近自然语言 tokenization 而受到关注。
- **痛点一：固定长度 1D 分词器缺乏自适应压缩能力**。大多数现有 1D 分词器在固定 token 长度下运行，无法在单一模型内调整压缩比，支持不同计算预算需训练多个模型变体。
- **痛点二：可变长度方案（嵌套 dropout）表示利用不充分**。以 FlexTok、Semanticist、One-D-Piece 为代表的方案采用嵌套 dropout，随机截断潜序列并保留前缀，使早期 token 承载最重要信息。但作者通过 ImageNet-1K 的码本统计发现：
  - 嵌套 dropout 导致**后段 token 位置码本多样性显著下降**（归一化熵低），出现“尾部 token 坍缩”（tail-token collapse）；
  - 码本平均利用率仅 **19.73%**，gFID 仅为 **2.46**，甚至不如固定长度基线（2.33）。
- **核心矛盾**：token 长度的灵活性 ≠ 额外 token 的有效利用。增加序列长度对下游 AR 生成可能收益递减甚至退化，说明**跨 token 长度的信息分配不均衡**：短前缀表示不足，后段 token 未能提供有效互补信息。
- **额外动机**：近期工作引入扩散/流式解码器提升质量，但增加了架构复杂度与解码延迟。本文坚持**离散可变长度分词器 + ViT 解码器 + 标准下一 token 预测**的简洁路线。
- **核心研究问题**：如何让单个分词器同时学到**信息量充足的前缀**与**有用的渐进式细化**，从而共同支撑高效的自回归生成？

## 2. 方法论

### 2.1 核心思想
NesTok 是一个基于 ViT 的可变长度 1D 分词器，通过**嵌套自对齐学习（nested self-alignment learning）**训练，无需任何外部蒸馏。核心由两部分组成：**跨长度联合训练**（cross-length joint training）与**嵌套自对齐损失**（nested self-alignment loss），旨在改善信息分配并建立**从粗到细（coarse-to-fine）**的 token 排序。

### 2.2 架构基础（基于 One-D-Piece）
- 输入图像 $x \in \mathbb{R}^{H\times W\times C}$ 被划分为 $f\times f$（$f=16$）不重叠 patch，映射为 patch embedding $x_p \in \mathbb{R}^{N\times D}$，$N=HW/f^2$。
- patch embedding 与可学习潜 token $q \in \mathbb{R}^{K\times D}$ 拼接后送入编码器：$[h_E, z] = E_\psi([x_p, q])$，丢弃 $h_E$，保留 1D 潜表示 $z$。
- 经向量量化得到 $z_q = Q(z)$，再与重复 $N$ 次的 mask token $m_p$ 拼接送入解码器：$[\varnothing, x_r] = D_\phi([z_q, m_p])$。
- 训练目标为四项复合损失：$\mathcal{L}_{rec} = \mathcal{L}_{mse} + \mathcal{L}_{perc} + \mathcal{L}_{quant} + \mathcal{L}_{adv}$，其中感知损失结合 LPIPS 与 ConvNeXt-S 特征损失；码本采用基于 EMA 使用率的自适应更新。

### 2.3 跨长度联合训练
- 每次训练迭代中，同时保留**全长序列** $z_q^{(K)}=[z_1,\dots,z_K]$ 和**随机采样的短前缀** $z_q^{(r_i)}$，其中 $r_i \sim \{1,\dots,K\}$。
- 两条序列共享全部参数，分别解码并累加损失：
$$\mathcal{L}_{joint} = \mathcal{L}_{rec}(x;K) + \mathcal{L}_{rec}(x;r_i)$$
- **作用**：全长序列保证每个潜 token 位置在每次迭代中至少参与一次解码，从而让尾部 token 只有通过补充前缀缺失的细节才能降低全长损失，使其成为**残差式细化**而非冗余复制。

### 2.4 嵌套自对齐损失
- 对 $n \in \{r_i, K\}$，提取解码器第 $\ell$ 层（默认 $\ell=1$）输出特征：$h_z^{(n,\ell)}, h_p^{(n,\ell)} = D_\phi^{(1:\ell)}(z_q^{(n)}, m_p)$。
- 由于两条序列潜 token 数量不同，对潜 token 维度做**平均池化**得 $\bar{h}_z^{(n,\ell)} = \text{Avg}(h_z^{(n,\ell)})$，将其视为单个 token 与 mask token 特征拼接：$f^{(n,\ell)} = \text{Concat}(\bar{h}_z^{(n,\ell)}, h_p^{(n,\ell)}) \in \mathbb{R}^{(N+1)\times d}$。
- 对齐损失（全长特征作为**在线目标**，带 stop-gradient）：
$$\mathcal{L}_{align} = 1 - \frac{1}{N+1}\sum_{j=1}^{N+1}\text{sim}\left(f_j^{(r_i,\ell)},\ \text{stopgrad}[f_j^{(K,\ell)}]\right)$$
- **作用**：在特征空间显式拉近短序列与全长序列的表示，无需额外教师网络；由于前缀是全序列的前缀，缩小该差距的最有效方式是**把全局布局与语义放在最早 token、把前缀无法承载的内容留给后续 token**。

### 2.5 总体目标与 AR 建模
- 总损失：$\mathcal{L}_{total} = \mathcal{L}_{joint} + \mathcal{L}_{align}$
- 下游生成采用标准自回归下一 token 预测：$p_\theta(z_{1:n}) = \prod_{i=1}^{n} p_\theta(z_i \mid z_{<i})$，在全长序列上以交叉熵训练；推理时可指定任意预算 $n\le K$，同一生成器采样 $n$ 长度前缀，并使用 KV-cache 加速。

## 6. 主要结论与发现

- **重建**：NesTok 以 256 token 达到 **rFID 0.98**，优于 One-D-Piece 的 1.08，且分词器参数更少（390M vs 641M）、无需外部蒸馏；相比可变长度 1D 基线（1.93）大幅提升。
- **生成**：搭配 LlamaGen，NesTok-XL 在 ImageNet 256×256 上取得**可变长度 AR 生成方法中的 SOTA gFID 1.46**（有 cfg），无 cfg 时 gFID 1.87；相比 One-D-Piece 的 2.35 显著提升。
- **码本利用**：平均码本利用率从 **19.73% 提升至 98.41%**，gFID 从 2.46 降至 1.92（Base 规模消融），并优于固定长度基线（2.33）。
- **信息分配**：NesTok 在各 token 位置保持码本多样性，熵呈**渐进下降**趋势，符合从粗到细的渐进式细化规律，缓解了尾部 token 坍缩。
- **可变长度一致性**：单个训练好的 AR 生成器在 32–256 token 全范围内均有效，且**质量随 token 数增加持续提升**——NesTok-L 与 NesTok-XL 在 128→256 区间分别降低 gFID 0.20 与 0.25；而 One-D-Piece-L 在大预算下反而退化（无 cfg 时 256 token gFID 高达 13.01），ReTok-L 收益递减（128→256 仅降 0.01）。
- **效率**：NesTok-L 在对比方法中 gFID 最优（1.50），吞吐量 16.35 images/s，优于 Diffusion 解码的 Semanticist（1.03）与 DetailFlow（19.69 但 gFID 2.75），在质量与延迟间取得较好折衷。
