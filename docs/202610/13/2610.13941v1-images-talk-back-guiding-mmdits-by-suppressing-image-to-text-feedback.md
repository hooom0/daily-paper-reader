## 摘要
多模态扩散 Transformer（MMDiT）通过联合注意力使演化中的图像更新内部文本表示。这些表示随后引导后续图像更新，由此引出一个问题：这种反馈有助于纠正与提示词的偏差，还是会保留这些偏差？我们发现，图像到文本（I2T）反馈会保留演化图像中已经表示的物体和属性，包括错误。移植 I2T 消息可以挽救失败，也可以破坏成功。在匹配的干预强度下，抑制 I2T 反馈的影响可改善生成，而相反的控制会使其退化。这些发现促使我们提出语义反馈引导（SFG）：它通过引导远离一个会增强该反馈并削弱文本到图像条件作用的辅助分支，来抑制 I2T 反馈的影响。原地变体 iSFG 直接抑制 I2T 反馈并增强文本到图像条件作用，且无需额外的模型评估。时间干预促使在图像采样步骤的前 20% 运行 SFG 分支；在不使用无分类器引导（CFG）时，约需基础 NFE 的 1.2 倍。在三个图像生成骨干网络上的实验表明，对齐度和偏好模型分数均有提升。在 FLUX 上，将 SFG 加入 CFG 使 GenEval 从 0.6661 提升至 0.7479；在 SD3.5M 上，iSFG 在零额外 NFE 的情况下相比 CFG 提升 +1.33 HPSv2.1。该控制也可迁移到文本到视频和图像到视频生成，提升 VBench 分数。代码见 https://github.com/yyc1215lll-creator/SFG。

## Abstract
Multimodal diffusion transformers (MMDiTs) allow the evolving image to update internal text representations through joint attention. These representations then guide subsequent image updates, raising a question: does this feedback help correct deviations from the prompt, or preserve them? We find that image-to-text (I2T) feedback can preserve the objects and attributes already represented in the evolving image, including errors. Transplanting I2T messages can rescue failures or disrupt successes. At matched intervention strengths, suppressing the influence of I2T feedback improves generation, whereas opposite controls degrade it. These findings motivate Semantic Feedback Guidance (SFG), which suppresses the influence of I2T feedback by guiding away from an auxiliary branch that strengthens this feedback and weakens text-to-image conditioning. The in-place variant, iSFG, directly suppresses I2T feedback and strengthens text-to-image conditioning, requiring no extra model evaluations. Temporal interventions motivate running the SFG branch during the first 20% of image sampling steps, requiring about $1.2\times$ the base NFE without classifier-free guidance (CFG). Experiments across three image-generation backbones show gains in alignment and preference-model scores. On FLUX, adding SFG to CFG raises GenEval from $0.6661$ to $0.7479$; on SD3.5M, iSFG adds $+1.33$ HPSv2.1 over CFG at zero extra NFE. The control also transfers to text-to-video and image-to-video generation, improving VBench scores. Code is available at https://github.com/yyc1215lll-creator/SFG.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：多模态扩散 Transformer（MMDiT）被 Stable Diffusion 3/3.5、FLUX、Qwen-Image、HunyuanVideo 等主流生成模型采用。其关键结构是同时维护**图像残差流**与**文本残差流**，二者通过联合注意力（joint attention）互相读取信息。
- **核心机制**：文本查询（text query）会读取图像键值（image keys/values），形成**图像到文本（I2T）消息** $B_{i\to t}$；随后后续模块又用被更新的文本流去条件化图像，形成"图像→文本→图像"的闭环反馈。
- **核心问题**：当演化中的图像偏离提示词时（例如提示词要求"苹果和橙子"，但图中只有苹果），I2T 反馈究竟会**纠正偏差**，还是会**固化已有内容（包括错误）**？
- **主要发现**：I2T 反馈会**保留**演化图像中已经表示的物体与属性，包括错误。移植 I2T 消息可以挽救失败，也可以破坏成功；在匹配干预强度下，**抑制** I2T 反馈能改善生成，而反向控制会使其退化。
- **整体含义**：该研究首次系统性地揭示并干预 MMDiT 中 I2T 反馈路径，为免训练引导方法提供了新的机制性方向（抑制反馈而非扰动模型）。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

- 通过**测量原生反馈路径**来选择扰动方向，而非像 PAG/SEG/S2-Guidance 那样通过模糊、恒等映射或跳块来"劣化模型"构造负分支。
- SFG 的负分支**增强 I2T 反馈并削弱 T2I 条件作用**，引导远离该分支即等价于**抑制反馈、强化条件作用**。

### 2.2 关键公式与符号

- **联合注意力输出**（式 1）：
  - 图像输出：$O_i = \underbrace{A_{i\to i}V_i}_{B_{t\to i}} + A_{t\to i}V_t$
  - 文本输出：$O_t = A_{t\to t}V_t + \underbrace{A_{i\to t}V_i}_{B_{i\to t}}$
  - 其中 $B_{i\to t}$ 为 I2T 消息，$B_{t\to i}$ 为 T2I 消息。

- **SFG 辅助分支**（式 3，$u<0$）：
  - $O^{pert}_t(u) = A_{t\to t}V_t + (1-u)B_{i\to t}$（SFG-X，增强 I2T）
  - $O^{pert}_i(u) = A_{i\to i}V_i + (1-|u|)B_{t\to i}$（SFG-S，削弱 T2I）

- **引导组合**（式 4）：$\hat{v} = v_{clean} + \omega(v_{clean} - v_{pert}) + (s-1)[v_{clean} - v_\theta(x_t,t,\varnothing)]$
  - $v_{clean}$：干净分支预测；$v_{pert}$：辅助分支预测；$\omega$：SFG 引导强度；$s$：CFG 强度。

- **iSFG 原地版本**（式 5）：
  - $O^{iSFG}_t = A_{t\to t}V_t + (1+\gamma)B_{i\to t}$，$\gamma<0$（抑制 I2T）
  - $O^{iSFG}_i = A_{i\to i}V_i + (1+\gamma_S)B_{t\to i}$，$\gamma_S>0$（强化 T2I）
  - 直接在条件前向传播中修改消息乘子，**无需额外模型评估**。

- **引导窗口**：移植实验表明步骤 1–8（共 40 步）可恢复约 2/3 的全调度救援效果，故图像任务采用前 20% 采样步激活 SFG 分支。

### 2.3 算法流程（文字描述）

1. 在干净条件前向中获取 $v_{clean}$；
2. 在同一 $x_t,t,c$ 下，以消息乘子 $a_X = 1-u$、$a_S = 1-|u|$ 运行辅助前向得到 $v_{pert}$；
3. 按式（4）外推得到 $\hat{v}$，可选叠加 CFG；
4. 仅在选定窗口内评估辅助分支；其余步骤走普通前向；
5. iSFG 则直接把乘子折入条件前向，零额外 NFE。

| 文本到视频 | VBench（7 维） | 326 prompts × 3 seeds = 978 视频 |
| 图像到视频 | VBench（8 维） | 355 prompts × 3 seeds = 1,065 视频 |

- **骨干模型**：SD3-Medium、SD3.5-Medium、FLUX（图像）；HunyuanVideo（视频）。
- **机制诊断**：400 对同提示成功/失败轨迹（SD3.5M 与 FLUX），用于移植实验与局部响应分析。

### 3.2 对比方法

- **图像**：PAG、SEG、S2-Guidance、TACA、Prompt Reinjection，以及 CFG 基线。
- **视频**：CFG、CFG-Zero⋆、S2-Guidance。
- 所有方法在相同 prompt、seed、初始噪声下对比；负分支算子（PAG 恒等替换、SEG 高斯模糊、S2 跳块）均按官方推荐配置并做了权重扫描。

### 3.3 消融实验

- **引导方向**：$|u|\in\{0.20,0.25,0.30,0.40\}$ × $\omega\in\{1,3,5\}$，共 12 组抑制设置 vs 12 组反向设置（SD3.5M，cfg=1）。
- **引导组件**：SFG-X、SFG-S、SFG 组合。
- **引导窗口**：25%/50%/75%/100% 活跃步数（图像与视频）。
- **机制实验**：消息移植（S→F、F→S、F→F、随机、T2I 对照）、局部响应方向（cosine gap over random）、对象遗漏探针（OSI 分类器，500 对 + 85 对队列）。

## 4. 资源与算力

- **文中明确提及**：iSFG 运行时测试使用 **单张 A800 80GB GPU**，BF16，1024² 分辨率，40 步，CFG 7.5，batch size 1；CFG 基线 10.800 s/图，CFG+iSFG 11.108 s/图（+2.86%）。
- **未明确说明**：
  - 论文**未披露**实验所用 GPU 总数、总训练时长或总推理计算预算；
  - 由于方法为**免训练（training-free）**，不涉及模型训练算力，但全量基准评测与消融的总计算量未量化；
  - 视频实验的算力细节未单独说明。

## 5. 实验数量与充分性

### 5.1 实验规模

- **3 个图像骨干** × 多个 benchmark（GenEval、T2I-CompBench++、HPSv2.1、ImageReward、FID）；
- **2 个视频任务**（T2V、I2V）× VBench 多维指标；
- **≥6 类消融**：引导方向、组件、窗口、移植、局部响应、对象遗漏探针；
- **超参扫描**：SFG 引导尺度 ω、各 baseline 权重 w（PAG/SEG/S2 均 5–6 点扫描）；
- **统计检验**：pairwise bootstrap、sign test；报告种子标准差（VBench 0.031，GenEval 0.00332）。

### 5.2 充分性与公平性评估

- **充分**：覆盖图像与视频、多种骨干、无 CFG 与叠加 CFG 两种配置，机制诊断与端到端评测相互印证。
- **客观公平**：
  - 同配置下所有方法共享 prompt、seed、初始噪声；
  - baseline 均做权重扫描取最优，未"低配"对比；
  - 使用官方评估器（Mask2Former GenEval）；
  - 移植实验设置 norm-matched 随机对照与 T2I 路径对照，排除一般性扰动解释。
- **潜在不足**：视频实验仅在一个骨干（HunyuanVideo）上验证；探针诊断依赖外部 OSI 分类器，其泛化性未独立验证。

## 6. 主要结论与发现

- **机制发现**：
  - I2T 反馈会**保留**演化图像中与提示词冲突的内容（错误固化）；
  - 成功供体移植可救援失败（67.5%），失败供体移植会破坏成功（60.5%），随机消息几乎无影响（1.3%）；
  - 局部响应分析显示，抑制反馈方向与成功移植方向一致（cosine gap over random 在所有时间区间为正）；
  - 早期干预（前 8/40 步）效果最大，晚期移植几乎无效。

- **方法效果**：
  - **无 CFG**：SD3M GenEval 0.3294→0.5811，FLUX 0.3604→0.6853；SD3M FID 41.76→24.21（优于 CFG s=7.5 的 32.49）。
  - **叠加 CFG**：FLUX GenEval 0.6661→0.7479（counting 0.6458→0.8167，position 0.1850→0.3033）；SD3.5M 0.6890→0.7110。
  - **iSFG（零额外 NFE）**：SD3.5M HPSv2.1 +1.33（31.65→32.98），ImageReward +0.0748；FLUX GenEval 0.6661→0.6868。
  - **视频迁移**：T2V VBench 总分 82.58→84.25；I2V 88.50→90.04。
  - SFG 修正方向与 CFG 近似正交，二者可有效叠加。

## 7. 优点

- **机制驱动的方法设计**：先通过移植实验与局部响应分析"测量"反馈路径，再据此确定引导符号，而非经验性试错，方法论上更具可解释性。
- **免训练、易集成**：仅需 patch 一个 SDPA 调用，兼容 diffusers 公共实现，不改变模型权重。
- **iSFG 零额外 NFE**：原地修改消息乘子，运行时开销仅约 2.86%，实用性强。
- **负分支构造新颖**：不同于 PAG/SEG 的"劣化模型"思路，SFG-X 通过**增强原生反馈**构造负分支，保留注意力计算完整性。
- **实验严谨**：配对轨迹设计、norm-matched 随机对照、T2I 路径对照、双侧符号验证、种子标准差报告，因果推断链条清晰。
- **跨模态泛化**：同一控制策略从 T2I 迁移到 T2V、I2V，验证了方法的通用性。

## 8. 不足与局限

- **算力信息不完整**：未报告 GPU 总数与总计算预算，复现成本难以估算；视频实验算力细节缺失。
- **引导窗口需任务调参**：图像用前 20%，T2V 用 7/25 步，窗口选择依赖经验，缺乏自适应机制。
- **抑制的副作用**：SFG-X 在救援失败的同时会破坏部分成功样本（500 对队列中 16.7% 成功被干扰；两物体场景更高达 26.4%）。
- **部分指标不及 CFG**：视频任务中 SFG 在背景一致性、美学质量上仍低于 CFG，dynamic degree 低于基线。
- **架构依赖**：方法针对 MMDiT 的联合注意力结构设计，对 UNet 或非联合注意力的 DiT 是否适用未验证。
- **探针依赖外部模型**：对象遗漏探针复用 OSI 的 per-head 线性分类器，其可靠性与跨模型泛化性未独立评估。
- **视频骨干单一**：仅 HunyuanVideo 一个视频模型，结论的跨骨干泛化性证据有限。
- **baseline 覆盖**：未与部分最新引导方法（如 CFG++、AG 等）对比；
