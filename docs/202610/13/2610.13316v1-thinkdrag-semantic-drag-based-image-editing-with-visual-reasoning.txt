THINKDRAG: SEMANTIC DRAG-BASED
IMAGE EDITING WITH VISUAL REASONING

ABSTRACT
Drag-based image editing provides an intuitive interface for spatially controlled
image manipulation by allowing users to specify handle and target points. Existing
methods have made substantial progress through optimization-based, one-step, and
feed-forward formulations, but they often interpret drag instructions as geometric
displacements. This limits their effectiveness when the desired edit depends on
interpreting image content and inferring a plausible semantic transformation from
sparse point constraints. We introduce THINKDRAG, a unified multimodal frame-
work for drag-based image editing with visual reasoning. THINKDRAG is trained to
associate point constraints with meaningful object- and scene-level transformations,
and can optionally produce an explicit reasoning trace that interprets the intended
edit before image generation. This reasoning trace improves interpretability, partic-
ularly for ambiguous drags. Drag Endpoint Markers, motivated by an analysis of
cross-image attention, provide an explicit correspondence signal that grounds each
drag in image space. To support this framework, we construct a supervised dataset
of semantic drag transformations paired with reasoning traces and introduce Drag-
Bench++, a benchmark targeting challenging drag-based editing scenarios with
reference edit solutions. Experiments show that THINKDRAG achieves state-of-the-
art performance, improving generation quality and plausibility while maintaining
competitive point-following precision.

INTRODUCTION
Image editing is a fundamental problem in generative modeling, where a model must modify visual
content while keeping the rest of the scene intact (Meng et al., 2022; Hertz et al., 2023; Brooks
et al., 2023). Beyond content creation, it also tests how well a model connects visual understanding
with controllable synthesis (Deng et al., 2025). Text-guided editing has made image manipulation
more accessible, but language alone often provides limited spatial precision. Many edits are easier
to specify by directly indicating where visual content should move, such as repositioning an object
part or changing a pose. Drag-based image editing (Pan et al., 2023; Shi et al., 2024) provides this
interface by allowing users to specify pairs of handle and target points, after which the model edits
the image by moving the content associated with each handle point toward its target.
Early methods such as DragGAN (Pan et al., 2023) demonstrated drag-based editing with GAN priors,
while diffusion-based methods extended it to broader visual domains (Shi et al., 2024; Mou et al.,
2024). Existing approaches typically rely on latent optimization (Zhang et al., 2025; Xia et al., 2025),
one-step latent editing (Zhao et al., 2024; Pu et al., 2026), or feed-forward generation conditioned on
point coordinates (Shin et al., 2024; Shi et al., 2025). However, they largely treat drag instructions as
spatial displacements and rely on the base generative prior for plausibility. This is limiting because
the same handle–target displacement can correspond to different valid edits depending on the object
and on what the user intends. For example, moving a point on an articulated object may require
rotating a part rather than translating a local patch.
Recent unified multimodal models (Zhou et al., 2025; Xie et al., 2025a; Deng et al., 2025) provide a
new opportunity for drag-based image editing. Unlike conventional image editors designed primarily
around synthesis (Brooks et al., 2023; Wu et al., 2025a; Black Forest Labs, 2025), these models
couple visual and language understanding with image generation in a single framework. This extends
the intuition behind DragGAN (Pan et al., 2023): if a generative prior enables drag editing within a
limited domain, then unified multimodal models can provide a broader prior for arbitrary images by

In this work, we introduce THINKDRAG, a unified multimodal framework for drag-based image
editing with visual reasoning. Given an input image and drag instructions, THINKDRAG generates
an edited image that satisfies the point constraints while preserving the semantic structure of the
scene. This is enabled by our new dataset of high-quality semantic drag edits, which teach the model
to associate sparse point constraints with plausible object- and scene-level transformations, paired
with reasoning traces that teach it to interpret the intended edit before generation. To execute drags
precisely, we further introduce Drag Endpoint Markers (DEM). Motivated by the observation that
each region of the edited image attends predominantly to the source region from which its content
originates, DEM explicitly encodes the correspondence between each handle and its target. As
illustrated in Figure 1, THINKDRAG uses visual reasoning to interpret ambiguous drag instructions
and can further incorporate user text when additional semantic guidance is provided. The model can
edit directly, or first reason when the edit is ambiguous or requires higher-level scene understanding.
We evaluate THINKDRAG on standard drag-editing benchmarks and introduce DragBench++, a new
benchmark targeting more challenging scenarios that require higher-level scene understanding and
semantic interpretation of point constraints. Extensive experiments show that THINKDRAG achieves
state-of-the-art performance, improving generation quality while maintaining competitive point-
following precision. The direct editing mode already performs strongly, reflecting the value of
semantic drag supervision and unified multimodal modeling. The reasoning mode complements
direct editing by making the model’s interpretation explicit, and it is particularly useful for ambiguous
multi-drag edits. In a user study, participants prefer THINKDRAG to prior methods in 80% of the
overall-preference votes on DragBench++ and 61% on DragBench.
Our contributions are summarized as follows:
• We introduce THINKDRAG, a unified multimodal framework for drag-based image editing
with visual reasoning, interpreting drag instructions with scene semantics and object structure.
• We construct, to our knowledge, the first supervised dataset of high-quality semantic drag
transformations with reasoning traces for training drag-based image editing models.
• We propose DragBench++, a benchmark targeting more challenging and semantically ambigu-
ous drag-based editing scenarios, with reference edit solutions.
• We achieve state-of-the-art results on drag-based editing benchmarks and support joint text-drag
conditioning, where text disambiguates user intent and drags provide precise spatial control.

RELATED WORK
2.1
UNIFIED MULTIMODAL UNDERSTANDING AND GENERATION
Multimodal understanding and image generation have traditionally followed different modeling
paradigms, with autoregressive vision-language models driving perception and reasoning (Liu et al.,

2023a; 2024b; Bai et al., 2023), and diffusion models dominating high-fidelity synthesis (Ho et al.,
2020; Song et al., 2021; Dhariwal & Nichol, 2021). Recent unified multimodal models combine
both capabilities in a single framework, either by tokenizing images and modeling them jointly with
text through next-token prediction (Chameleon Team, 2024; Wang et al., 2024; Wu et al., 2025b;
Chen et al., 2025) or by coupling autoregressive language modeling with diffusion-based visual

chain-of-thought (Wang et al., 2025; Shao et al., 2024) and generator-coupled reasoning (Qin et al.,
2026; He et al., 2026) further show a growing ability to connect visual perception, language reasoning,
and image synthesis, but their use for spatially grounded image manipulation remains underexplored.
2.2
DRAG-BASED IMAGE EDITING
Drag-based image editing provides intuitive image manipulation by dragging user-specified handle
points to target positions. DragGAN (Pan et al., 2023) introduced this paradigm through latent
optimization with motion supervision and point tracking, but its GAN prior limits generalization
to arbitrary real images. Diffusion-based methods extend drag editing to broader domains, mostly
through test-time optimization (Shi et al., 2024; Mou et al., 2024; Hou et al., 2024; Ling et al., 2024;
Liu et al., 2024a; Cui et al., 2024; Zhang et al., 2025; Jiang et al., 2025; Choi et al., 2025; Xia et al.,
2025; Zhou et al., 2026; Lin et al., 2025) or faster one-step and training-free alternatives (Nie et al.,
2024; Zhao et al., 2024; Lu et al., 2024; Lu & Han, 2025; Yin et al., 2026; Pu et al., 2026; Jhong et al.,
2026; He et al., 2025). Most related to our work are feed-forward methods that frame drag-based
editing as conditional generation. InstantDrag (Shin et al., 2024) and LightningDrag (Shi et al., 2025)
synthesize edited images directly from point or motion conditions derived from videos, treating drags
as geometric constraints, while Cui et al. (2024) infer the intended edit with an LLM at test time. In
contrast, THINKDRAG interprets drag instructions within a unified multimodal model and grounds
edits through an explicit correspondence signal in image space, learned from semantic drag edits.

THINKDRAG
3.1
DATASET CONSTRUCTION
Prior work (Shin et al., 2024; Shi et al., 2025) has shown that videos provide a natural source
of paired supervision for drag-based image editing. These pipelines typically sample source and
target images from a temporal window and recover motion using optical flow or point tracking.
However, video-derived supervision has several limitations. Extracted correspondences are primarily
geometric and may not reflect semantically meaningful edit intent, optical flow can be unreliable
under large displacement or occlusion, and natural videos often contain camera motion or background
variation that corrupts the desired edit supervision. We therefore construct the THINKDRAG dataset,
a new drag-based image editing dataset that emphasizes high-quality image pairs and semantically
meaningful point instructions. Figure 2 gives an overview of the pipeline, described below.
Synthetic Image Pair Generation.
Drag-based image editing is best suited to transformations
that can be expressed through spatial motion of existing visual content, such as object translation,
pose change, non-rigid deformation, and local geometric warping. It is less appropriate for edits
involving semantic discontinuities (e.g., object insertion and removal, or global style transfer). Based
on this distinction, we construct synthetic image pairs through an automated MLLM-assisted pipeline.
We first use an MLLM (Bai et al., 2025) to generate diverse source-image prompts from a pool of
subjects and environments, and synthesize source images using state-of-the-art text-to-image models,
including Qwen-Image (Wu et al., 2025a), FLUX.2 (Black Forest Labs, 2026), and Z-Image (Cai
et al., 2025). Given each source image, the MLLM proposes image-specific edit prompts constrained
to be compatible with drag-like transformations. The source image and edit prompt are then passed
to the editing model FLUX.2 (Black Forest Labs, 2026; fal, 2025) to synthesize the target image, and
an MLLM-based binary filter discards low-quality or invalid pairs.
Semantic Keypoint Matching.
From the filtered pairs, we recover each edit as semantic drag
instructions. We prompt Gemini 3 Pro (Google, 2025) to identify keypoints that explain the transfor-
mation between the source and target images. Each drag consists of a handle point, a target point, and
a semantic description of the matched element in both images. This converts the synthetic pair into

Reasoning Chain Creation.
Finally, we generate reasoning chains for each drag-edit example
using Gemini 3 Flash (Google, 2025). The dataset construction pipeline makes the intended edit
recoverable by construction: the MLLM has access to the source image, edited image, edit prompt,
and semantic keypoint correspondence annotations. We use this information to prompt the MLLM to
produce a reasoning chain that explains the source scene, interprets each drag in semantic terms, and
summarizes the intended transformation while specifying which regions should remain unchanged.
Since each source–target pair can be used bidirectionally, we generate reasoning chains for both edit
directions. These traces provide supervision for reasoning-driven drag-based editing.
Dataset Statistics.
Starting from approximately 193K generated pairs, MLLM filtering retains 97K,
keypoint matching 50K, and verification yields the final dataset of approximately 11K source–target
image pairs from 7K source images. Since each pair can be used in both directions, by swapping the
source and target images and reversing the drag endpoints, this yields approximately 22K drag-based
editing samples. During training, we further apply standard spatial augmentations such as horizontal
flips and random crops. Figure 3 shows how the dataset spans diverse semantic drag transformations.
Samples contain 2.15 drags on average (74% with multiple drags) and reasoning traces of 123 words
on average. Edit category distribution and per-stage details are provided in Appendix C.

EXPERIMENTS
4.1
EXPERIMENTAL SETUP
Benchmarks.
We evaluate on DragBench (Shi et al., 2024), the standard benchmark for drag-based
image editing. We also introduce DragBench++, a new benchmark constructed using our dataset
construction pipeline in Sec. 3.1 for image pair generation. DragBench++ contains 145 samples
with manually annotated drag instructions and emphasizes scenarios that require higher-level scene
understanding, object-level reasoning, and semantic interpretation, with more drags per sample and
longer displacements than DragBench (Table 2). Unlike prior benchmarks, each input also includes a
pseudo-ground-truth edited image as reference. Although drag-based editing is under-constrained
and multiple outputs may satisfy the same instruction, this reference edit verifies that each example
has at least one plausible solution. It also enables reference-based evaluation and a more controlled
analysis of whether existing metrics reflect meaningful editing quality. Reference edits are used only
for evaluation. Baselines that require an edit mask receive manually annotated masks.
Evaluation Metrics.
We evaluate along two axes: editing accuracy and generation quality. For
editing accuracy, we follow prior work (Shi et al., 2024) and report Mean Distance (MD), which
measures the distance between each target point and the corresponding handle point tracked in the
generated image using DIFT (Tang et al., 2023), restricted to the edit mask. On DragBench++,
reference edits show that DIFT-based correspondence can be unreliable under semantic ambiguity or
large structural changes. We therefore also report MDMLLM, which uses the same distance definition
but replaces DIFT with GPT-5.5 (OpenAI, 2026) for point tracking, computed for the strongest
method of each category (Appendix B.2). Since GPT-5.5 is not used in our data pipeline, data
construction and evaluation are decoupled. For generation quality, we report Image Fidelity (IF) and
FID (Heusel et al., 2017). Following prior work, IF is computed as 1 −LPIPS (Zhang et al., 2018)
between the input image and generated edit. Since fidelity to the input is ambiguous for editing tasks,
where the output should preserve irrelevant content while changing the edited region, we also report
FID on DragBench to measure overall visual quality and realism. For DragBench++, we instead
report IF* against the reference edits as the primary fidelity metric.
4.2
COMPARISON WITH BASELINES
Quantitative Evaluation.
We compare against state-of-the-art drag-based image editing methods
with public official implementations: test-time optimization methods DragDiffusion (Shi et al., 2024),
DragNoise (Liu et al., 2024a), and DragLoRA (Xia et al., 2025); one-step methods FastDrag (Zhao
et al., 2024) and GeoDrag (Pu et al., 2026); and fine-tuned conditional generation methods Instant-
Drag (Shin et al., 2024) and LightningDrag (Shi et al., 2025). Table 1 reports quantitative results
on DragBench and DragBench++, with THINKDRAG in direct mode. Across both benchmarks,
THINKDRAG achieves the best generation quality, with the highest IF and lowest FID on DragBench,
and the best IF and IF* on DragBench++. On DragBench, THINKDRAG remains competitive in
point-following accuracy, although the strongest MD scores come from test-time optimization and
one-step methods that explicitly enforce the point displacement at inference. The advantage is clearer
on DragBench++, where edits require stronger semantic interpretation. THINKDRAG achieves the
best MD and MDMLLM. The reference row also shows that DIFT-based MD is less reliable in this
setting, since even reference edits obtain a relatively high MD. MDMLLM provides a more semantic
estimate, under which THINKDRAG substantially outperforms the baselines. The improvement in
IF* further shows that THINKDRAG does not improve point accuracy by producing implausible
distortions; its outputs remain closest to the reference edits.

User Study.
We conduct a user study with 30 participants, each answering 20 questions sam-
pled evenly from DragBench and DragBench++. For each question, participants see the input
image, the drag instruction, and anonymized outputs of DragLoRA, GeoDrag, LightningDrag, and
THINKDRAG in random order, and select the preferred result for edit accuracy, generation quality,
and overall preference. As shown in Table 3, participants clearly prefer THINKDRAG, with 80% of
the overall-preference votes on DragBench++ and 61% on DragBench, an external benchmark inde-
pendent of our data pipeline, and similar shares for the other criteria (Appendix B.3). On DragBench,
THINKDRAG also receives 62% of the edit-accuracy votes despite a higher DIFT-based MD than all
three baselines, suggesting that MD does not fully capture semantic correctness.
4.3
JOINT TEXT-DRAG CONDITIONING
In the default setting, THINKDRAG infers the intended edit from the input image and drag points alone,
either directly or through its reasoning chain. Joint text-drag conditioning provides a complementary
mode where the user specifies part of the semantic intent. This is useful when the same point
motion admits multiple plausible interpretations, since drag points provide spatial anchors while text
clarifies the desired transformation. Prior work has explicitly targeted this setting with specialized
mechanisms (Jiang et al., 2025). In THINKDRAG, it follows naturally from the unified multimodal
formulation. During training, we condition the model on both drag endpoints and the corresponding
text edit description for 10% of samples, allowing it to learn text-drag interaction without making
text mandatory at inference time. As shown in Figure 7, the same drag instruction can be resolved
into different valid edits when paired with different text prompts, such as widening a flower versus
opening its petals, or enlarging the candle body versus extending the flame.

5
CONCLUSION
We introduced THINKDRAG, a unified multimodal framework for drag-based image editing with vi-
sual reasoning. By training on a new dataset of high-quality semantic drag transformations and reason-
ing traces, and by grounding each drag with Drag Endpoint Markers, THINKDRAG learns to interpret
sparse point constraints in relation to scene content and object structure, rather than treating them only
as geometric displacements. We also introduced DragBench++, a benchmark of more challenging
drag-based editing scenarios with reference edits. Experiments show that THINKDRAG achieves
state-of-the-art generation quality while maintaining competitive point-following precision, with the
reasoning mode providing additional interpretability, particularly for ambiguous multi-drag edits.

B.1
IMPLEMENTATION DETAILS
We implement THINKDRAG using BAGEL (Deng et al., 2025) as the base unified multimodal model.
We train LoRA adapters (Hu et al., 2022) of rank 256 on the attention and MLP projections of the base
transformer for 100K steps, using AdamW with a learning rate of 2 × 10−5 and a cosine schedule.
The effective batch size is approximately 16 samples, distributed across 4 NVIDIA H200 GPUs. The
training procedure takes around 60 hours. We set the reasoning loss weight to λthink = 0.25. We
support up to 10 drag pairs per image during training; this limit is configurable. Unless otherwise
specified, inference uses 50 sampling steps with classifier-free guidance scales of 3.0 for text and 1.5
for image conditioning. The learned endpoint scales remain close to their initialization (αtgt ≈1.16,
αsrc ≈1.12). Images are processed at their native aspect ratio, with training images mostly square
and the remainder in 4:3 and 16:9 in both orientations. The number of drags per sample (1–7) follows
the annotation without random subsampling. The arrows and points drawn in our figures serve only
as visualization, since the model receives drags solely as text and DEM. For the zero-shot rows of
Table 5, BAGEL and FLUX.2 receive the drags as structured text instructions.
B.2
MLLM-BASED EVALUATION
For the MDMLLM metric, we use GPT-5.5 (OpenAI, 2026) to track source handle points in the
generated image. The model receives the source image, the generated image, and the source handle-
point coordinates. It is prompted to return the corresponding physical or semantic point locations
in the generated image using normalized coordinates in [0, 1000]. Due to API cost, we compute
MDMLLM for the strongest method of each category (DragLoRA, GeoDrag, and LightningDrag), the
same baselines as in the user study, and mark the remaining methods with “–” in Table 1. Figure 11
compares this protocol with DIFT-based tracking. Although MLLM-based tracking is also imperfect,
it is more robust in challenging cases involving semantic ambiguity, large structural changes, or
visually similar distractors, where local feature matching can select an incorrect correspondence.
On the reference edits of DragBench++, which satisfy their drags by construction, DIFT reports a
mean distance of 43.42, whereas GPT-5.5 reports 27.38. Most of the DIFT distance on this benchmark
therefore reflects tracking failures under large structural changes. On DragBench, where edits are
more local, DIFT remains accurate, so we report both trackers and regard them as complementary.
Prompt for MLLM-based point tracking
You are a highly precise vision-language model. You see two images in order:
SOURCE then GENERATED.
Your task is point tracking. The user provides handle point coordinates in the
SOURCE image. For each provided source handle point, return the corresponding
same physical/semantic point location in the GENERATED image.
Critical rules:
- Track the exact same point or landmark.
- The source handle point may have moved, deformed, or changed appearance in
the generated image.
- Use nearby object geometry, part boundaries, corners/tips/joints/hinges,
texture, and semantic context to identify the correspondence.
- If a point is occluded or not visible in the GENERATED image, set its target
to the nearest visible point.
- Coordinates are normalized to 0-1000: (0,0) top-left, (1000,1000)
bottom-right of the GENERATED image.
- Return exactly one entry per input point, preserving the input point index.
- Do not include markdown or prose.
Output STRICT JSON:
{"tracked_points":[{"index":0,"target":[x,y]}]}

User study instructions
User Study on Drag-based Image Editing
You will be shown 20 questions with an input image, a drag instruction,
and edited results.
For each example, answer the following three questions:
Editing Accuracy:
Select the result that best follows the drag instruction. Focus on whether
image content moves from the handle point to the target point and the intended
edit is achieved.
Generation Quality:
Select the result with the best visual quality for the given edit. Focus on
image quality, realism, lack of artifacts, and preservation of regions that
should not change.
Overall Preference:
Select the result you prefer overall, considering both editing accuracy and
generation quality.
The edited results are shown in random order.

LIMITATIONS AND FUTURE WORK
While THINKDRAG achieves strong drag-based editing performance across both standard and chal-
lenging scenarios, several limitations remain. First, the reasoning mode introduces additional infer-
ence latency due to autoregressive reasoning generation, and its benefit is concentrated in ambiguous
multi-drag edits. Although direct editing remains available and already performs strongly, future
work could study distillation or adaptive reasoning strategies that invoke reasoning only when the edit
is ambiguous. Second, our reasoning is expressed in language space, which provides interpretability
but may not fully capture fine-grained visual transformations. A promising direction is to explore
reasoning directly in latent or pixel space, where intermediate representations could encode spatial
transformations more explicitly. Finally, although DragBench++ expands evaluation toward more
semantic and ambiguous edits, drag-based editing remains under-constrained, and automatic metrics
only partially reflect human preference. Future benchmarks could develop more robust evaluation
protocols for settings where multiple valid edits can satisfy the same instruction.
