## 摘要
少步文本到图像生成器通过少量网络前向传播即可生成高质量图像，但在涉及多个主体、交互、空间关系、计数和属性绑定的复杂提示上仍表现不佳。能否在不改变生成器参数或不增加其前向传播次数的情况下减少这些错误？我们提出了一种用于冻结的6B参数生成器的轻量级校正框架。生成器预测速度，这些速度决定其中间图像表示如何更新；一个参数少于2000万的校正器在选定的采样步骤学习残差调整。由于较早的校正会改变后续步骤遇到的状态，我们的 On-Trajectory Flow-Bridge Supervision 在实际校正生成过程中到达的状态上推导残差目标。单个校正器在选定的步骤间共享，并与生成器并行运行。仅训练校正器，既不需要奖励优化，也不需要重新蒸馏。据我们所知，这是首个针对完全冻结的少步文本到图像生成器进行轻量级速度残差适配、并保持其原始采样计划和前向传播次数的框架。在我们的目标复杂场景分布上，该框架在成对指令遵循评估中相较于冻结的 Z-Image-Turbo 取得了 +17.60 个百分点的 NetWin，每张图像仅增加 26.9 ms（0.84%）的端到端延迟，且骨干网络评估次数没有增加。

## Abstract
Few-step text-to-image generators produce high-quality images with few network forward passes, yet struggle with complex prompts involving multiple subjects, interactions, spatial relations, counting, and attribute binding. Can these errors be reduced without changing the generator's parameters or increasing its forward-pass count? We propose a lightweight correction framework for a frozen 6B-parameter generator. The generator predicts velocities that determine how its intermediate image representation is updated; a corrector with fewer than 20M parameters learns residual adjustments at selected sampling steps. Because earlier corrections change the states encountered at later steps, our On-Trajectory Flow-Bridge Supervision derives residual targets at the states actually reached during corrected generation. A single corrector is shared across selected steps and runs in parallel with the generator. Only the corrector is trained, requiring neither reward optimization nor re-distillation. To our knowledge, this is the first framework for lightweight velocity-residual adaptation of fully frozen few-step text-to-image generators that preserves their original sampling schedule and forward-pass count. On our target complex-scene distribution, the framework achieves a +17.60-percentage-point NetWin over frozen Z-Image-Turbo in pairwise instruction-following evaluation, with only 26.9 ms (0.84%) additional end-to-end latency per image and no increase in backbone evaluations.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：少步文本到图像（T2I）生成器（如 8 步的 Z-Image-Turbo）通过极少的网络前向次数即可产出高视觉质量图像，但在复杂提示上遵循能力不足，尤其体现在**多主体、主体交互、空间关系、计数、属性绑定**等场景。
- **核心问题**：能否在**不改变生成器参数、不增加前向传播次数、不改变采样计划**的前提下，减少少步生成的指令遵循错误？
- **关键观察**：作者发现 50 步 Z-Image 在复杂指令遵循上明显强于 8 步 Z-Image-Turbo（在 574 条复杂场景提示上 NetWin 领先 +19.5 pp）；对比两者从同一初始噪声出发的轨迹，发现**中间更新方向差异显著**（角度从 37.1° 增至 54.5°），但相对更新幅度大致相当（比值 0.85–1.46×）。
- **研究含义**：这提示"中间速度"是可干预的切入点——不必重训或再蒸馏生成器，只需在冻结骨干上对速度场做轻量残差校正，即可提升少步生成对复杂提示的遵循能力。

## 2. 方法论

### 2.1 核心思想
保持 6B 参数生成器**完全冻结**，仅训练一个 **<20M 参数的校正器**，在选定采样步上为生成器预测的隐空间速度添加残差修正；校正器与生成器**并行执行**，不增加骨干前向次数，也不改变采样计划。

### 2.2 关键技术细节

- **问题设定**：少步生成采用 Euler 形式速度参数化，噪声调度 σ₁=1 > … > σ_K > σ_{K+1}=0，K=8（Z-Image-Turbo）。原始更新为 z_{k+1}^B = z_k^B + h_k·v_θ(z_k^B, σ_k, c)，其中 h_k = σ_{k+1}-σ_k < 0。

- **(a) 并行速度残差校正（Parallel Velocity Residual Correction）**
  - 从 z₁^C = ε 出发，在活跃步集合 S ⊆ {2,…,K} 上施加校正器 r_φ。
  - 校正器输入为**当前隐状态 z_k^C**与**缓存的上一生成器速度 v_{θ,k-1}^C**（外加文本条件 c 与噪声水平 σ_k）。
  - 采用紧凑 **S3-DiT** 架构：6 个 Transformer 块、隐维度 384、3 个注意力头、头维度 128、patch size 2，约 18.6M 参数。
  - 复用生成器预计算的文本 token 嵌入，**无需额外文本编码前向**；文本与图像 token 联合注意力。
  - 校正速度：v̂_k = v_θ,k^C + r_φ,k（k∈S），否则 v̂_k = v_θ,k^C；z_{k+1}^C = z_k^C + h_k·v̂_k。
  - 因为不依赖当前骨干输出（仅用缓存的前一步速度），两支可**并发执行**。

- **(b) 轨迹内流桥监督（On-Trajectory Flow-Bridge Supervision）**
  - 训练时校正后状态 z_k^C 由**在线 rollout** 产生，而非预计算基线轨迹；基线状态上的残差目标在 z_k^C 处不再有效。
  - 构造从初始噪声到目标隐变量的**线性参考桥**：b_k = (1-σ_k)z* + σ_k ε，其中 z* = E(x*)，b₁=ε，b_{K+1}=z*。
  - 残差目标：r*_k = sg[(b_{k+1} - z_k^C)/h_k - v_{θ,k}^C]（sg 为 stop-gradient）。
  - 可分解为两项互补作用：
    - **参考速度校正**：v_FB - v_{θ,k}^C，v_FB = (b_{k+1}-b_k)/h_k = ε - z*；
    - **轨迹恢复**：(b_k - z_k^C)/h_k，补偿当前状态偏离参考桥的位移。
  - 对固定当前状态，残差预测误差直接决定下一状态桥误差：z_{k+1}^C - b_{k+1} = h_k(r_{φ,k} - r*_k)。

- **(c) 共享多步学习（Shared Multi-Step Learning）**
  - **单个**噪声条件校正器在多个选定步间共享，用局部监督训练。
  - 损失：L_local(φ) = E[ (1/|S|) Σ_{k∈S} ρ_β(r_{φ,k} - r*_k) ]，ρ_β 为 Smooth L1（β=2），各活跃步在速度残差空间等权。
  - 输出投影**零初始化**，使训练从原始生成器轨迹出发。
  - rollout 状态与缓存速度在步间 **detach**，不通过前序校正或采样更新反向传播。
  - 默认 S = {2,3,4}（**早期步**干预），留出后续冻结更新吸收残差误差。
  - 推理时同一校正器在相同活跃步施加，其余由冻结生成器完成。

## 7. 优点

- **问题定位清晰**：先通过轨迹分析（方向差异 vs 幅度相似）实证定位"中间速度"为干预点，动机扎实。
- **方法设计精巧**：
  - 校正器仅用当前隐状态 + 缓存前一步速度，实现与生成器**真正并行**，无额外前向、不改采样计划；
  - On-Trajectory Flow-Bridge 解决"早期校正改变后续状态"的分布偏移问题，目标在线重算；
  - 单校正器跨步共享 + 局部监督，避免通过采样更新反向传播，训练代价低；
  - 零初始化输出投影保证从原始轨迹平滑起步。
- **效率与效果兼顾**：<20M 参数、0.84% 延迟开销换取 +17.60 pp，性价比显著优于 LoRA 微调、DPO、D-OPSD 与 DiffCon。
