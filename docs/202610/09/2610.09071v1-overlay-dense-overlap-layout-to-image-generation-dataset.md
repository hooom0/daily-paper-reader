## 摘要
布局到图像生成在空间和对象级控制方面已取得实质性进展。然而，现有方法仍难以处理包含许多重叠且相互作用的对象的复杂场景。我们认为训练数据是一个特别的瓶颈：现有数据集缺乏具有密集、复杂对象交互的样本。为弥补这一空白，我们提出了 OverLay++，一个具有结构复杂场景的大规模布局到图像数据集。OverLay++ 包含约 50 万张图像，平均每张图像有 6.6 个对象，标注密度比现有数据集高 1.67 倍。除标注密度外，OverLay++ 还提供丰富的语义细节，其对象描述长度超过当前数据集的六倍。我们的数据集生成流程简单，并能生成密集、重叠的对象标注以及丰富的逐对象描述。在多个基准上，基于 OverLay++ 数据集训练的最先进布局到图像方法表现出一致的改进和更快的收敛，证明了密集、感知重叠且描述丰富的监督对于可控图像生成的重要性。

## Abstract
Layout-to-Image generation has made substantial progress in spatial and object-level control. However, existing methods still struggle with complex scenes containing many overlapping and interacting objects. We argue that training data is a particular bottleneck: existing datasets lack examples with dense, complex object interactions. To address this gap, we introduce OverLay++, a large-scale Layout-to-Image dataset with structurally complex scenes. OverLay++ contains approximately 500K images with an average of 6.6 objects per image, exceeding existing datasets by 1.67 times in annotation density. Beyond annotation density, OverLay++ provides rich semantic detail with object captions over six times longer than in current datasets. Our dataset generation pipeline is simple and produces dense, overlapping object annotations with rich per-object captions. Across multiple benchmarks, state-of-the-art Layout-to-Image methods trained on the OverLay++ dataset show consistent improvement and faster convergence, demonstrating the importance of dense, overlap-aware, and caption-rich supervision for controllable image generation.

- **研究领域**：布局到图像（Layout-to-Image, L2I）生成，即在给定全局文本描述与场景布局（每个布局元素包含一个边界框和一条局部文本描述）的条件下生成图像，属于可控图像生成的重要分支。
- **核心痛点**：现有 L2I 方法（包括基于 U-Net 的 GLIGEN、InstanceDiffusion，以及基于 DiT/SD3/FLUX 的 EliGen、SiamLayout）在**包含大量重叠、交互对象的复杂场景**中仍然表现不佳，常见失败模式包括对象缺失、属性缺失、密集布局处理不当。

### 四阶段数据构建流程

1. **图像过滤（Image Filtering）**
   - 基于 LAION-Aesthetics Predictor V2，保留美学分 ≥ 5.98 的图像；
   - 要求 `min(H, W) ≥ 1024`，随后确定性中心裁剪为 1024×1024；
   - 此阶段后得到 **850,900 张**图像。

2. **对象检测（Object Detection）**
   - 使用 **Qwen3-VL-32B** 检测所有显著对象，输出结构化三元组：`(语义类别, 归一化边界框 [x1,y1,x2,y2], 详细局部描述)`；
   - 提示词中**强制要求**每个边界框与至少一个其他框存在重叠、最小边 ≥ 51 像素（约 5% 分辨率）；
   - 过滤掉有效检测少于 5 个的图像，以鼓励密集布局。

3. **场景过滤（Scene Filtering）**
   - 对每个候选检测，裁剪对应区域并用 Qwen3-VL-32B 做**二值验证**（"该对象是否存在于裁剪区域？"），剔除幻觉或低质量检测；
   - 再次剔除剩余有效检测少于 5 个的图像，最终保留 **499,249 张**。

4. **分层描述生成（Captioning）**
   - 同样由 Qwen3-VL-32B 完成，提供**两个粒度 × 两个层级**共四类文本：
     - 场景级：长全局描述（一两句话描述整体场景）、短全局描述（< 20 词，关键对象与场景）；
     - 对象级：长局部描述（检测阶段生成，含外观/风格/视觉特征）、短局部描述（< 20 词，身份 + 显著属性）；
   - 长/短设计旨在兼容不同 token 上限的文本编码器（如 CLIP 的 77 token 限制）。
   - 注：词数限制是**提示词指令**而非事后截断，表中报告的是实际观测长度。

## 六、主要结论与发现

1. **一致性能提升**：在 LayoutSAM-Eval 上，EliGen-SD3 (Ours) 在全部区域级指标上达到 SOTA，颜色 +8.52%、纹理 +7.39%、形状 +7.48%，FID 下降 22.09%；SiamLayout-SD3 (Ours) 取得最佳 FID（17.96）。
2. **密集场景增益最大**：在 OverLayBench-Complex 上，EliGen-SD3 (Ours) 的 mIoU +14.59%、O-mIoU +34.92%、SRE +12.95%，说明密集重叠监督对复杂场景尤为关键。
3. **收敛更快**：训练曲线显示，OverLay++ 训练的模型在 Simple / Regular / Complex 三档上均更快达到更高 IoU。
4. **描述粒度结论**：**短局部描述 + 长全局描述**组合最优——短局部利于对象定位（CLIP 77 token 限制），长全局提供场景上下文。长局部描述在 SD3 上反而下降，但在使用 T5 长上下文路径的 FLUX 上带来显著增益（SRE 最高 +11.54%）。
5. **解耦消融结论**：即使把局部描述压缩到比 EliGen 更短（1.88 词），仅增加对象数量仍能大幅提升局部指令遵循指标；进一步加长描述再带来额外增益。
6. **人工评估佐证**：OverLay++ 训练的模型「是」比例整体高 **+11.80 个百分点**，各难度档均胜出。

## 七、优点与亮点

- **问题定位精准**：把 L2I 复杂场景失败归因到数据侧，用可量化的指标（最近邻 IoU、最近邻距离、描述词数）刻画数据缺陷，论证扎实。
- **数据构建流程简单可复现**：四阶段流水线全部基于开源模型（Qwen3-VL-32B、LAION-Aesthetics），无需人工标注，且加入**逐对象 grounded 验证**有效抑制幻觉。
- **多层级、多粒度标注设计**：同时提供场景级/对象级 × 长/短的 4 类文本，兼容不同 token 上限的编码器，显著提升数据可用性。
- **评估体系完整**：区域级 + 全局级指标并重，自动评估与人工评估互补，并公开数据集与网站。
- **诚实性**：附录中明确标注消融实验的局限（无法完全隔离变量、算力受限、Long-CLIP 复评的适用范围），学术态度严谨。

## 八、不足与局限

- **继承 MLLM 偏差与标注噪声**：整个流程依赖 Qwen3-VL-32B 做检测、验证与描述，数据集可能继承其偏见、幻觉与失败模式。
- **场景覆盖仍有盲区**：对罕见对象交互、透明物体、稀有类别等困难情形覆盖不足；长尾类别（如乐器、武器、车辆）占比极低（0.6%–2.0%）。
- **变量解耦不彻底**：对象数量、重叠度与描述长度在真实数据中相互纠缠，现有消融无法完全分离三者各自的贡献，因果归因仍有保留。
