Abstract
Layout-to-Image generation has made substantial progress in spatial and object-
level control. However, existing methods still struggle with complex scenes con-
taining many overlapping and interacting objects. We argue that training data
is a particular bottleneck: existing datasets lack examples with dense, complex
object interactions. To address this gap, we introduce OverLay++, a large-scale
Layout-to-Image dataset with structurally complex scenes. OverLay++ contains
approximately 500K images with an average of 6.6 objects per image, exceeding
existing datasets by 1.67× in annotation density. Beyond annotation density, Over-
Lay++ provides rich semantic detail with object captions over six times longer than

Introduction
While text-to-image diffusion models [Saharia et al., 2022, Ramesh et al., 2021, Nichol et al., 2022,
Rombach et al., 2022, Chen et al., 2024a, Xue et al., 2023] have achieved remarkable progress in
generating high-quality and realistic images, they provide imperfect control over visual attributes
such as spatial arrangement, color, and texture. This has led to a growing interest in controllable
image generation [Li et al., 2023a, Zhang et al., 2023, Xie et al., 2023, Wang et al., 2024a, Lee et al.,
2024, Chen et al., 2025, 2024b, Tan et al., 2025, Zhao et al., 2025, Binyamin et al., 2025, Yang et al.,
2023, Srivastava et al., 2026], where users provide additional conditions, such as depth maps [Zhou
et al., 2024a, 2025], human pose [Zhang et al., 2023], or scene layouts [Li et al., 2023a, Zhang et al.,
2025a], to guide generation. Among these conditions, scene layouts provide a direct way to specify
object locations, counts, and object-level attributes, thereby supporting a broad range of controllable
image generation scenarios. Specifically, in Layout-to-Image generation [Zhang et al., 2025a,b, Wang
et al., 2024a, Li et al., 2023a, Zhang et al., 2023, Zhou et al., 2024b, Lee et al., 2024], the model is
conditioned on a global text caption and a scene layout. Each layout element consists of a bounding
box that specifies the object’s location and a local text caption that describes the object.
Layout-to-Image generation methods typically adapt diffusion models [Song and Ermon, 2019,
Ho et al., 2020, Song et al., 2020, Dhariwal and Nichol, 2021, Ho and Salimans, 2022, Rombach
et al., 2022, Ramesh et al., 2022, Saharia et al., 2022, Esser et al., 2024, Srivastava et al., 2025]
pretrained on internet-scale datasets [Schuhmann et al., 2022, Gadre et al., 2023, Byeon et al., 2022]
to support layout conditioning. Recent methods [Zhang et al., 2025a,b] use stronger backbones
such as SD3 [Esser et al., 2024] and FLUX [Black Forest Labs, 2024], where multimodal DiT
blocks [Peebles and Xie, 2023] allow layout, visual, and text information to be combined within a
shared architecture. However, current methods still struggle in complex scenes with many objects,
particularly when objects overlap [Li et al., 2025]. We argue that these failures reflect limitations
in existing training data: current datasets contain few dense, overlapping layouts, and their local
captions often omit object-level details needed to control color, texture, and interactions.
Existing datasets for Layout-to-Image generation are largely adapted from object detection [Lin et al.,
2014, Shao et al., 2019] and visual grounding datasets [Plummer et al., 2015, Peng et al., 2023], which
contain relatively few dense object interactions. Further, object annotations typically use class names
or short phrases, providing little detail about object attributes. More recent data-collection efforts,
including the dataset proposed by EliGen [Zhang et al., 2025b] and LayoutSAM [Zhang et al., 2025a],
improve these annotations and object density with foundation models such as GroundingDINO [Liu
et al., 2023] for improved object grounding and Qwen2-VL [Wang et al., 2024b] for detailed object
annotations. However, these data-generation pipelines do not specifically target scenes with dense,
overlapping objects, leaving such scenes underrepresented in the resulting datasets.
To address this gap, we introduce OverLay++, a large-scale dataset for dense and overlap-aware
Layout-to-Image generation. OverLay++ contains approximately 500K images with an average of 6.6
objects per image, along with short and long captions at both the global and per-object levels. Notably,
even our short captions are 6× longer than those in existing datasets. We construct OverLay++ using
a simple and robust pipeline that prompts MLLMs to generate overlapping object proposals and
applies per-object grounded validation. This produces images with dense layouts, substantial overlap,
rich captions, and high instance-level accuracy. Training state-of-the-art L2I methods on OverLay++
improves performance across multiple benchmarks, and we find that models trained on OverLay++
converge faster than corresponding baselines trained on existing datasets, highlighting the value of
dense, overlap-aware, and caption-rich supervision.
Our contributions are summarized as follows:
1. We introduce OverLay++, a large-scale dataset for dense and overlap-aware Layout-to-
Image generation. OverLay++ contains approximately 500K images with an average of 6.6

Notably, the short captions in OverLay++ are 6× longer than those in existing datasets.
2. We design a simple and robust dataset generation pipeline that targets dense, complex

Related Work
2.1
Layout-to-Image Generation
Layout-to-Image (L2I) makes Text-to-Image (T2I) models more controllable for real-world applica-
tions, enabling image synthesis that is both visually realistic and spatially grounded. L2I methods
typically adapt text-to-image diffusion models [Song and Ermon, 2019, Ho et al., 2020, Song et al.,
2020, Dhariwal and Nichol, 2021, Ho and Salimans, 2022, Rombach et al., 2022, Ramesh et al.,
2022, Saharia et al., 2022, Esser et al., 2024, Srivastava et al., 2025], pretrained on internet-scale
datasets [Schuhmann et al., 2022, Gadre et al., 2023, Byeon et al., 2022]. Broadly, existing L2I
methods can be divided into training-free and training-based approaches. Training-free methods [Lee
et al., 2024, Chen et al., 2025, Bar-Tal et al., 2023, Kim et al., 2023, Chefer et al., 2023, Xie et al.,
2023, Gani et al., 2023, Yang et al., 2024, Chen et al., 2024c] avoid modifying the underlying T2I
model and instead encourage objects to appear within their intended spatial regions through inference
modification (e.g., altering attention maps or modifying classifier-free guidance). While attractive for
their simplicity and compatibility with off-the-shelf models, these methods provide limited control in
complex scenes and perform worse than training-based counterparts [Li et al., 2025].
On the other hand, training-based methods modify the underlying T2I architecture to incorporate
layout conditions. Early L2I methods [Li et al., 2023a, Wang et al., 2024a, Zhou et al., 2024b,
Cheng et al., 2024] were largely built on latent-diffusion U-Net [Ronneberger et al., 2015] backbones
and introduced layout information through layout-specific adapters, spatial masks, gated attention
layers, or ControlNet [Zhang et al., 2023]-like module additions. For example, GLIGEN [Li et al.,
2023a] adds gated self-attention layers that incorporate bounding-box conditions into a pretrained
SD-1.5 diffusion model. Similarly, InstanceDiffusion [Wang et al., 2024a] incorporates various
spatial conditioning schemes with specialized fusion layers. Although these methods demonstrated
the effectiveness of layout conditioning, their generation quality and controllability are constrained
by the representational capacity of U-Net backbones, especially in dense scenes. Recent L2I methods
leverage stronger multimodal DiT [Peebles and Xie, 2023] backbones, such as SD3 [Esser et al.,
2024] and FLUX [Black Forest Labs, 2024]. Compared with earlier U-Net-based models, these
backbones offer greater modeling capacity and improved image realism. As a result, recent works
incorporate layout information into DiTs through text-like layout tokens, region-level attention masks,
or multimodal conditioning mechanisms [Zhang et al., 2025a,b]. While there has been significant
progress in algorithm design, these models still struggle to handle complex scenes with numerous
overlapping objects. Our work instead focuses on improving the training data by constructing denser
layouts with higher levels of object overlap and richer local and global descriptions, ensuring that L2I
models can learn complex object interactions and generate visually and spatially coherent images.
2.2
Training Datasets for Layout-to-Image Generation
Early Layout-to-Image (L2I) generation methods, including GLIGEN [Li et al., 2023a], were typically
trained on object detection [Shao et al., 2019, Lin et al., 2014] and grounding datasets. While these
datasets provide bounding-box annotations, their localized annotations are usually class labels rather
than descriptive object-level captions. This sparsity limits their utility for training L2I models, where
fine-grained object descriptions are important for controllable generation.
To address this limitation, InstanceDiffusion [Wang et al., 2024a] generated dense object-level
captions by first extracting objects with pretrained tagging models [Zhang et al., 2024a], detecting

per-object grounded validation, ensuring high instance-level accuracy in the images.
3
Dataset Curation Pipeline
3.1
Motivation and Design Goals
Existing layout-to-image datasets such as LayoutSAM [Zhang et al., 2025a], EliGen [Zhang et al.,
2025b], and GRIT [Peng et al., 2023] contain limited examples of complex scenes.
First, many commonly used datasets contain relatively sparse object layouts. As shown in Table 1,
prior datasets include only 1.78–3.93 objects per image on average, which limits their ability to
supervise dense multi-object generation. Beyond object number, we directly measure object density:
for each bounding box, we identify its nearest neighbor based on center-to-center distance, then
measure the intersection-over-union (IoU) for that pair. Mean NN IoU reflects the degree of overlap
between nearby objects, while Mean NN Dist measures normalized spatial proximity in [0, 1]
bounding box space. Existing datasets generally exhibit low NN IoU and relatively large NN distance,
indicating that nearby objects often have weak local spatial interactions.
4


Second, existing datasets usually provide limited language supervision. As summarized in Table 1,
most prior datasets rely primarily on image-level captions or sparse textual descriptions, without
systematically providing object-level appearance descriptions tied to individual bounding boxes. This
weakens supervision for fine-grained object attributes and makes it difficult for models to jointly
learn global scene semantics and local object appearance from layout-conditioned data.
Based on these observations, our design goals are to construct a Layout-to-Image dataset with denser
object layouts, stronger local spatial interactions, and richer multi-level language supervision. As
shown in Table 1, our dataset substantially improves these key properties over existing datasets,
including object density, nearest-neighbor spatial interaction, and annotation granularity. The detailed
curation and annotation procedures used to achieve these improvements are described in the follow-
ing subsections. Specifically, we develop an automated pipeline based on the LAION-Aesthetics
V2 [Schuhmann et al., 2022] 4.75 subset (956M images), consisting of four stages: 1) Image Filtering,
2) Object Detection, 3) Scene Filtering and 4) Captioning.

3.2
Image Filtering
Given the highly variable quality of web-scraped data, we first filter the corpus using the LAION-
Aesthetics Predictor V2 [Schuhmann et al., 2022], retaining only images with an aesthetic score of
at least 5.98. This step ensures that the retained images have strong compositional and perceptual
quality, providing a high-quality visual basis for dense layout construction. We additionally discard
any image where either spatial dimension falls below 1024 pixels, enforcing min(H, W) ≥1024.
Images that satisfy both criteria are then center-cropped deterministically to a standardized resolution
of 1024 × 1024 pixels. After this filtering step, we obtain 850,900 images.
3.3
Object Detection
To address the lack of dense objects in existing datasets, we explicitly construct object-dense scenes.
We prompt the model, Qwen3-VL-32B [Bai et al., 2025a], to detect all visually salient objects
and return structured predictions consisting of: (i) a semantic category label, (ii) a bounding box
in [x1, y1, x2, y2] format normalized to a 1024-pixel coordinate space, and (iii) a detailed caption
describing each object’s visual attributes. After the detection result, to further encourage dense
layouts, images with fewer than five valid detections after applying these constraints are discarded.
3.4
Scene Filtering
To further reduce hallucinated or low-quality detections, we perform per-object validation. For each
candidate detection, the corresponding image region is cropped and re-evaluated using Qwen3-VL-
32B with a binary prompt that asks whether the described object is present in the cropped region.
Detections for which the model returns a negative response are removed. Afterwards, to ensure the
density of the objects, images with fewer than five remaining valid detections after this validation
step are discarded. 499,249 images are kept after this step.

3.5
Captioning
We use Qwen3-VL-32B to do scene-level captioning. The retained images are annotated with
complementary textual fields at two levels of granularity: scene-level descriptions and object-level
descriptions. Scene-level captions provide holistic semantic context for the full image, while object-
level captions describe the appearance and attributes of individual objects associated with specific
bounding boxes.
While detailed captions are a valuable supervision signal, some layout-to-image methods use language
encoders with short token limits [Ramesh et al., 2022]. To increase dataset accessibility while
preserving semantic supervision, we provide both long and short captions.
A long scene-level caption is prompted to describe the overall image, including its main objects
and their attributes, whereas a short scene-level caption is prompted to use fewer than 20 words
and provides a compact summary of the key objects and context. Similarly, the long object-level
caption, generated during the object detection stage, provides a detailed description of each object’s
appearance, style, and visual characteristics. In contrast, the corresponding short object-level caption,
also prompted to use fewer than 20 words, captures the object’s identity and salient visual attributes.
Together, these annotations provide both scene-level and object-level supervision. This design directly
addresses the limitations of prior datasets by producing layouts with more objects, stronger local
spatial interactions, and richer hierarchical annotations. The prompts are provided in Appendix A.1.
The word limits are prompt instructions rather than post-generation truncation rules, and Table 1
reports observed caption lengths.

Evaluation
4.1
Implementation Details
We evaluate the OverLay++ dataset using two state-of-the-art Layout-to-Image generation methods,
EliGen [Zhang et al., 2025b] and SiamLayout [Zhang et al., 2025a]. For EliGen, we use the publicly
released code to train separate layout-conditioned models on the EliGen and OverLay++ datasets,
starting from a pretrained SD3 backbone. Both models are trained for 10K steps with a per-GPU
batch size of 12 on 8×A6000 GPUs and a learning rate of 3 × 10−4. The OverLay++ EliGen-SD3
run uses short local captions and long global captions. For SiamLayout, since the training code is not
publicly available, we fine-tune the released model on OverLay++ for 60K steps with a per-GPU
batch size of 2, gradient accumulation of 2, and a learning rate of 5 × 10−5 on 8×A6000 GPUs. We
compare against the SiamLayout-SD3 results reported in the original paper [Zhang et al., 2025a]. All
models are optimized with the AdamW [Loshchilov and Hutter, 2019] optimizer with a weight decay
of 0.05, β1 = 0.9, and β2 = 0.95. We use a constant learning rate and a classifier-free guidance [Ho
and Salimans, 2022] scale of 7.5 for generation. We compare our dataset on three benchmarks:
LayoutSAM [Zhang et al., 2025a], OverLayBench [Li et al., 2025], and DenseLayout [Xiang et al.,
2025].
4.2
LayoutSAM Benchmark
LayoutSAM-Eval [Zhang et al., 2025a] is a Layout-to-Image generation benchmark built from a subset
of LayoutSAM and contains 5,000 layouts. It evaluates generation quality from two perspectives:
region-wise quality and global quality. Region-wise quality uses VLM-based VQA to measure
whether each object appears in the correct bounding box and whether its attributes, such as color,
texture, and shape, match the local descriptions. Global quality is summarized using FID [Heusel
et al., 2017] and Inception Score (IS) [Salimans et al., 2016], which measure distribution-level image
fidelity and diversity.
Results are reported in Table 2. Training on OverLay++ consistently improves each model over its
corresponding baseline. Eligen-SD3 (Ours) achieves state-of-the-art results on all region-wise quality
metrics, with gains of up to 8.5%. SiamLayout-SD3 (Ours) achieves the best FID and the second-best
IS among all methods, demonstrating the effectiveness of training with the OverLay++ dataset.

4.5
Caption Granularity
We ablate the effect of caption granularity by training EliGen-SD3 with different combinations of
short and long captions at the local and global levels. Results are shown in Table 5. The Short-Long
setting achieves the best overall results, suggesting that short local captions are more effective for
object grounding while long global captions provide useful scene-level context. This is likely due to
the CLIP text encoder used for local prompts, which is limited to 77 tokens and may truncate longer
object descriptions. With stronger local text encoders or longer context windows, long local captions
may provide additional gains.
5
Conclusion, Limitations, and Broader Impact
We introduced OverLay++, a large-scale dataset for dense and overlap-aware Layout-to-Image
generation. OverLay++ contains approximately 500K images with an average of 6.6 objects per image,
exceeding existing datasets by 1.67× in annotation density, and provides caption-rich supervision with
short and long captions at both the global and per-object levels. Across multiple benchmarks, state-
of-the-art L2I methods trained on OverLay++ show consistent improvements and faster convergence,
highlighting the importance of dense and overlap-aware supervision for controllable image generation.
Despite these improvements, OverLay++ has several limitations. Since our pipeline uses MLLMs
for captioning and grounding visual entities, the dataset may inherit model biases and annotation
noise. In addition, although the OverLay++ dataset focuses on dense scenes with overlapping objects,
it may still underrepresent difficult cases such as unusual object interactions, transparent objects,
and rare object categories. OverLay++ is intended to support the development of more reliable
Layout-to-Image models for real-world and industrial applications, where fine-grained visual control
and spatially grounded image synthesis are basic requirements. However, because the dataset is
constructed using open-source foundation models, it may inherit the same biases, failure modes, and

A.1
Prompts
To construct OverLay++, we employ Qwen3-VL-32B [Bai et al., 2025a] throughout the dataset
curation pipeline for object detection, scene filtering, and hierarchical caption generation.
The prompts are designed to encourage dense and overlap-aware annotations while seeking to reduce
hallucinated object annotations and provide rich semantic descriptions. Specifically, the object
detection prompt explicitly encourages overlapping bounding boxes and detailed object-centric
descriptions, while the scene filtering stage performs per-object validation to remove hallucinated
detections. In addition, we generate both global and local captions at long and short granularities
to support different Layout-to-Image architectures with varying text encoder capacities. The exact
prompts used in each stage are provided below.

A.2
Long Local Captions with a Long-Context Text Encoder
The degraded performance with long local prompts in Table 5 may reflect truncation in EliGen-SD3’s
local-prompt encoder path. The CLIP path has a 77-token limit [Radford et al., 2021], while long
local captions average 89.70 words, making truncation plausible. This is a hypothesis rather than a
direct measurement of truncation’s effect.
To test long local captions directly, we fine-tune the released EliGen-FLUX model, whose local
prompts use a longer-context T5 path, on the OverLay++ dataset with long local captions. Due to
limited compute, we train for 5K steps with a batch size of 8. The FLUX results are consistent with
the possibility that a longer-context local-prompt path can use more of the caption detail. As shown
in Table 6, our model improves over the EliGen-FLUX baseline on nearly every metric across all
three OverLayBench splits, with large gains on region-aware metrics (e.g., SRE improves by up to
11.54% on the Complex split) as well as better FID. The only exception is a marginal drop in CLIPG
on the Regular split. Table 7 shows the same trend on LayoutSAM-Eval: our model improves over
EliGen-FLUX on all region-wise metrics (Spatial, Color, Texture, Shape) as well as on FID and IS.

A.3
Global Alignment with Long-CLIP
The global prompts in OverLayBench average 79.66, 86.81, and 82.91 words on the Simple, Regular,
and Complex splits, respectively, exceeding the 77-token input limit of CLIP. We therefore reevaluate
global text–image alignment with Long-CLIP [Zhang et al., 2024b], which supports up to 248 tokens.
As shown in Table 8, the OverLay++-trained EliGen-SD3 model has slightly higher Long-CLIPG
scores than its baseline on all three splits. This comparison changes the evaluation encoder; it does
not test a change to the generation model’s local-prompt encoder.
A.4
Source of the Improvements
We examine the effects of object count and local caption length using two ablations on the SD3
backbone, each trained for 2K steps. For the 450K-image ablation subset, we remove the 50K
OverLay++ images with the highest nearest-neighbor IoU, reducing its mean from 0.31 in the full
dataset to 0.27, close to EliGen’s 0.26. Dataset composition and object count are not identical
across all settings, so these comparisons do not isolate either factor perfectly. Results on the three
OverLayBench splits (Simple, Regular, Complex) are reported in Table 9.
We compare EliGen-SD3, trained on the EliGen dataset (2.56 objects/layout, 2.12-word local cap-
tions), against EliGen-SD3 (Ours, incr. objects), trained on the OverLay++ dataset with local captions
restricted to a brief object description (mean 1.88 words, shorter than EliGen’s). The settings differ
in object count (6.68 vs. 2.56 objects/layout), caption length, and potentially other dataset properties;
Table 1 reports different nearest-neighbor IoU values for the full datasets. Despite using shorter
captions, training on OverLay++ consistently outperforms EliGen on all local instruction-following
metrics (mIoU, O-mIoU, SRE, SRR, and CLIPL) across all three OverLayBench splits.
We then train EliGen-SD3 (Ours, incr. caption len), which replaces the brief object descriptions
above (mean 1.88 words) with the short local captions of the OverLay++ dataset (mean 15.89
words), with a slightly different mean object count (6.59 rather than 6.68). The longer-caption setting
improves mIoU, O-mIoU, and SRE across all three splits. SRR improves on Simple and Regular but
decreases on Complex; CLIPL decreases across all three. Both settings use 2K training steps, so
these differences cannot be attributed to fewer steps.

A.6
Dataset Composition
Existing Layout-to-Image datasets are largely adapted from object detection or grounding datasets,
and therefore come with explicit class labels drawn from a fixed set of categories. In contrast,
OverLay++ is open-domain: object categories are generated directly by Qwen3-VL-32B as free-form
text during detection, rather than selected from a predefined class list.
To give a sense of the dataset’s composition, we perform zero-shot classification of the short local
prompts into 26 broad semantic groups. Table 12 reports the number of bounding boxes in each
group, where count refers to the number of bounding boxes belonging to that group, along with
its share of all boxes. The dataset covers a broad range of content, from furniture and home decor,
clothing and accessories, and hair and hairstyles to surfaces (walls and floors) and natural scenery
(sky and clouds, flowers and gardens, mountains and landscape), with a long tail of less frequent
categories such as musical instruments, weapons and armor, and vehicles.
