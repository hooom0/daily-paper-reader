多参考图像生成需要在将多个主体组合成连贯场景的同时，保持它们的外观。然而，现有扩散Transformer通常将参考编码为密集的视觉token网格，并用全局注意力联合处理，随着参考数量和分辨率的增长，条件成本变得越来越高。我们提出RefRoute，一个通过两种互补机制同时解决参考表示成本和注意力开销的框架。紧凑残差条件将低分辨率潜在token与从全分辨率像素中提取的轻量残差特征相结合，在减少参考token数量的同时保留细粒度外观线索。条件路由与注意力路由将参考token与其分配的目标区域对齐，并限制跨参考交互，同时允许选择性跨越区域边界访问参考，以实现场景整合。我们进一步提出RefRoute-Data用于训练多参考生成模型，以及ManyRef100，一个涵盖人物、物体和混合组合且包含10-17个参考的基准。经过多参考微调后，RefRoute在ManyRef100上取得36.06的总体Weighted-Ref-VIEScore，而FLUX.2-Klein-9B为8.88。独立的推理成本评估显示，随着参考数量增加，延迟增长显著更慢：在16个参考时，我们的50步和4步配置分别相比对应的FLUX基线实现18.3倍和14.2倍加速。这些结果确立了紧凑参考表示和空间路由注意力作为可扩展多参考图像生成的一种有效方法。

## Abstract
Multi-reference image generation requires preserving the appearance of multiple subjects while composing them into a coherent scene. However, existing diffusion transformers commonly encode references as dense visual token grids and jointly process them with global attention, making conditioning increasingly expensive as the number and resolution of references grow. We present RefRoute, a framework that addresses both reference representation cost and attention overhead through two complementary mechanisms. Compact residual conditioning combines low-resolution latent tokens with lightweight residual features extracted from full-resolution pixels, reducing reference token counts while retaining fine-grained appearance cues. Condition routing and attention routing align reference tokens with their assigned target regions and restrict cross-reference interactions, while allowing selective reference access beyond region boundaries for scene integration. We further introduce RefRoute-Data for training many-reference generation models and ManyRef100, a benchmark spanning human, object, and mixed compositions with 10-17 references. After many-reference fine-tuning, RefRoute achieves an overall Weighted-Ref-VIEScore of 36.06 on ManyRef100, compared with 8.88 for FLUX.2-Klein-9B. Separate inference-cost evaluations show substantially slower latency growth as the reference count increases: at 16 references, our 50-step and 4-step configurations achieve $18.3\times$ and $14.2\times$ speedups over their corresponding FLUX baselines, respectively. These results establish compact reference representations and spatially routed attention as an effective approach to scalable many-reference image generation.

# RefRoute 论文中文结构化总结

## 一、核心问题与研究动机

- **背景**：多参考（multi-reference）图像生成要求模型在保持多个主体外观（身份、材质、纹理等）的同时，把它们组合进一个连贯场景。当前多模态扩散 Transformer（DiT）的主流做法是把每张参考图编码为**密集视觉 token 网格**，再与文本 token、噪声目标 token 拼接成统一序列，用**全局注意力联合处理**。
- **核心痛点**：联合注意力的复杂度为 O((N_g + Kn)²)（N_g 为目标 token 数，K 为参考数，n 为单张参考 token 数）。一张 1024×1024 参考经 VAE 产生 64×64=4096 个 token，16 张参考即 65536 个 token，参考迅速主导输入序列。作者由此指出两类"不必要的计算"：
  - **表示规模膨胀（representation scaling）**：token 数随参考数量与分辨率线性增长，但生成所需的信息量并不必然随之增长；单纯降分辨率又会丢失高频外观线索。
  - **交互规模膨胀（interaction scaling）**：即使压缩表示，标准拼接仍使注意力图稠密——每个目标 token 可与所有参考 token 交互，不同实体的参考之间也可互相交互，导致属性–主体错绑、身份泄漏与空间混乱。
- **设计原则**：条件成本应随"输出所需的信息量与空间支撑"扩展，而不是随"输入的分辨率与全局连通性"扩展。
- **整体含义**：论文把该问题定义为**条件成本如何随参考数量缩放**，并主张必须同时解决表示与交互两个瓶颈（只压缩表示不能阻止全局注意力，只做空间掩码不能阻止 token 数增长），从而提出 RefRoute 框架。

## 二、方法论

### 2.1 问题形式化

- 给定文本 c、目标图像 x₀ 与参考 {rᵢ}，经 VAE 编码为潜变量；噪声状态 zₜ=(1−t)z₀+tϵ；文本嵌入 T、目标嵌入 X、参考嵌入 Cᵢ_r 拼接为统一序列 [T; X; C¹_r; …; C^N_r]，由 DiT 联合处理。
- 每个视觉 token 赋坐标 (τᵢ, h, w)（τᵢ 标识来源图像），通过 RoPE 注入位置信息。
- 训练目标为标准 flow matching：L_FM = E[‖v_θ(zₜ,t,c,{rᵢ}) − (ϵ − z₀)‖²₂]。

### 2.2 紧凑残差条件化（Compact Residual Conditioning）

- **固定 token 预算**：参考先下采样 4×，再经 VAE 编码，得到 16×16=256 token（原为 64×64=4096）。表示成本与参考分辨率解耦。
- **像素残差补偿**：引入轻量 **Pixel Residual Compressor P**，直接从全分辨率像素提取互补特征，与低分辨率潜 token 在空间网格与 token 数上对齐；经**零初始化投影** Proj₀ 映射到 DiT 隐藏维后，在**第一个 DiT block 之前**一次性逐元素相加：
  - Cᵢ_r = Proj_in(Zᵢ_lr) + Proj₀(P(rᵢ))
- **压缩器预训练**：每次迭代采样两类任务之一——重建任务（目标即参考自身）或主体驱动生成任务（目标为同主体在不同姿态/视角/场景下的图像），均用 flow matching 目标。前者鼓励忠实编码外观，后者鼓励可迁移的身份与外观线索。
- **收益**：在 K=16 时，参考相关注意力成本约降低 **70×**（忽略文本 token）。

### 2.3 条件路由与注意力路由（Condition & Attention Routing）

- **条件路由（Condition Routing）**：
  - 使用**分离的 reference LoRA 与 spatial LoRA** 适配器做条件特定适配：reference adapter 作用于文本流与视觉流，spatial adapter 作用于视觉流，二者在后续合并流中均生效。
  - **位置重映射**：为补偿紧凑参考的分辨率下降，把参考 token 的 RoPE 坐标由 (τᵢ, h, w) 重映射为 (τᵢ, sh, sw)（s 为下采样因子），使其与目标潜网格处于同一空间尺度。
- **注意力路由（Attention Routing）**：
  - Q/K/V 组织为 U = [U_T; U_X; U_{C¹r}; …; U_{C^Nr}; U_{Cs}]，用加性路由偏置 M 控制注意力：Attn = Softmax(QKᵀ/√d_k + M)V；允许连接处 M=0，禁止处 M=−∞。
  - **参考流隔离**：参考 query 只能访问自身参考 token、文本 token、空间条件 token，**不能**访问噪声目标 token 或其他参考；文本 query 可访问所有组；目标 query 可访问文本、目标、空间条件；空间条件 query 只访问空间条件 token。
  - **区域绑定与选择性越界**：设 Ωᵢ 为参考 rᵢ 负责的目标 token 区域，Ωᵢ 内的目标 query 可访问 Cᵢ_r 的全部 token；Ωᵢ **之外**的目标 query 只允许访问**排名最高的单个参考（top-1）**的全部 token，其余参考被屏蔽。该选择在**参考级别**而非 token 级别进行，从而既保持显式的参考–区域对应，又允许阴影、光照、接触等跨边界效果（消融显示严格掩码会导致人物"漂浮"，动态 top-1 路由保留脚与地面接触）。

### 2.4 训练流程与数据构建

- **三阶段训练**：Stage 1 预训练 Pixel Residual Compressor（T2I，K=1）；Stage 2 用多参考+空间条件联合训练（含路由机制，K=1–5 主实验，K>5 为 high-K 续训）；Stage 3 按 TBSM 做蒸馏。
- **RefRoute-Data**：每条记录含目标图、场景描述、逐实例参考、框与掩码，提供显式参考–实例对应。规模为 20,000 个物体场景（143,249 个保留实例）与 1,000 个人物场景（4,123 人、4,067 张导出参考）。构建分四阶段：提示生成 → 目标合成（物体用 HiDream-I1-Full，人物用 GPT，1024×1024）→ 实例标注（GroundingDINO / 人检测+姿态+人脸匹配 + SAM）→ 验证与参考构建（FLUX.2-klein-4B 生成影棚风格参考，ArcFace 余弦 ≥0.50 时复用输入身份图）。
- 论文指出 MICo 数据集的三个局限：89.2% 案例 ≤5 个参考、缺少实例级空间标注、人物参考常与目标身份不匹配；RefRoute-Data 的参考–目标 ArcFace 平均相似度为 **0.53**，而 MICo-150K 人物子集为 0.19。

## 四、实验结果与分析

### 4.1 少参考场景（MICo-Bench）

- 在 2–5 个参考的主流设定下，RefRoute 与各强基线（含闭源模型与 MICo 微调系）总体持平或在主体保真与文本对齐上略有优势，说明路由与紧凑条件化**不牺牲**低参考数下的常规性能。
- 相对未改造的 FLUX.2-Klein 主干，RefRoute 在保持同等生成质量的同时降低了参考相关计算开销，体现"同等质量、更低条件成本"的设计目标。

### 4.2 多参考场景（ManyRef100）

- 在 10–17 个参考的高 K 设定下，基线方法的退化明显：闭源模型倾向遗漏或合并主体，开源拼接式方法出现属性–主体错绑与身份泄漏；RefRoute 在实例覆盖率、身份保持与空间落位上领先幅度最大。
- 效率上，随 K 增大，RefRoute 的参考相关注意力成本增长显著平缓；结合固定 token 预算（每参考 256 token），K=16 时相对标准拼接约有 **70×** 的注意力成本缩减，使其在相同显存下可承载更多参考。

### 4.3 缩放行为分析

- **表示维度**：固定 token 预算使表示成本与参考分辨率解耦，高分辨率参考不再线性推高序列长度；像素残差补偿则以极低开销补回高频外观线索。
- **交互维度**：路由偏置把稠密注意力图变为稀疏可控图，目标 token 不再与所有参考 token 交互，参考之间也彼此隔离，从机制上抑制了错绑与泄漏。
- 二者结合对应论文的设计原则——条件成本随"输出所需信息量与空间支撑"扩展，而非随"输入分辨率与全局连通性"扩展。

## 五、消融实验

- **紧凑残差条件化**：去掉 Pixel Residual Compressor 仅用低分辨率潜 token，主体细节与纹理保真下降，验证像素残差的互补作用；去掉零初始化投影会破坏训练初期稳定性。
- **注意力路由**：
  - 完全去掉路由（退化为全局拼接）→ 高 K 下错绑与身份泄漏显著上升；
  - 采用**严格掩码**（区域内目标 query 只访问对应参考）→ 跨边界效果缺失，人物出现"漂浮"、脚与地面接触丢失；
  - 采用**token 级**选择性越界 → 路由不稳定、参考–区域对应模糊；
  - 论文的**参考级 top-1 越界**在保持显式参考–区域对应的同时恢复阴影、光照与接触，是消融中的最优配置。
- **条件路由**：分离 reference / spatial LoRA 与位置重映射共同作用；去掉位置重映射会使紧凑参考与目标潜网格尺度不匹配，空间落位变差。
- **参考数 K 的影响**：性能随 K 增大先升后趋稳，路由机制使高 K 下不出现基线的明显崩塌。

## 六、贡献与创新点

1. **问题定义**：把多参考生成的瓶颈明确拆解为"表示规模膨胀"与"交互规模膨胀"，并提出条件成本应随输出需求而非输入规模扩展的设计原则。
2. **紧凑残差条件化**：固定 token 预算 + 像素残差压缩器 + 零初始化投影，在解耦分辨率的同时保留高频外观信息。
3. **条件与注意力路由**：分离 LoRA 适配、RoPE 位置重映射与加性路由偏置，实现参考流隔离、区域绑定与参考级 top-1 选择性越界。
4. **数据与基准**：构建 RefRoute-Data（显式参考–实例对应，人物参考 ArcFace 平均相似度 **0.53**，远高于 MICo-150K 人物子集的 0.19）与 ManyRef100（10–17 参考、带实例级标注）基准。

## 七、局限性

- 路由依赖参考–区域对应关系，训练与推理均需实例级空间标注或框/掩码输入，纯文本驱动、无空间先验的场景适用性受限。
- top-1 选择性越界的规则较为手工化，跨区域复杂交互（多主体相互遮挡、密集接触）仍可能不足。
- 三阶段训练（压缩器预训练、联合训练、蒸馏）流程较长，复现与调参成本较高。
- 主干为 FLUX.2-Klein-9B，方法在其他 DiT 主干上的通用性尚待更广泛验证。

## 八、总体评价

RefRoute 的价值不在于单点模块，而在于把"多参考条件化"从"堆更多 token、算更稠密注意力"的粗放范式，转向**预算化表示 + 结构化交互**的可控范式：固定 token 预算解决输入侧膨胀，路由偏置解决注意力侧膨胀，像素残差与选择性越界则在压缩后补回信息与跨边界效果。实验上，它在少参考场景不降质、在高参考场景显著缓解错绑与泄漏，并给出与设计原则一致的缩放曲线；其数据构建与 ManyRef100 基准也为后续多参考研究提供了可比较的评测面。主要待解问题集中在空间先验依赖与规则化路由的泛化上。
