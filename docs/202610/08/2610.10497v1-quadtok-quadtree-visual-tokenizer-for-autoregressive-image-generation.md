## 摘要
我们提出了 QuadTok，一种用于视觉分词和自回归图像生成的新颖框架。与使用二维网格或一维 token 序列的传统方法相比，我们提出了一种分层四叉树结构，弥合了二维空间绑定与一维序列级灵活性之间的差距。QuadTok 分词器将表征能力动态分配给视觉上复杂的区域，同时使同质区域保持粗粒度分辨率。与固定的 256 token 网格相比，我们在 ImageNet 上训练的分词器在 ImageNet 上节省约 10% 的 token，在零样本迁移到 COCO 数据集时节省 9%，同时保持相当的重建保真度。此外，树结构引入的自然因果性无缝支持自回归图像生成。在生成前提供四叉树拓扑作为条件，我们的 947M GPT 风格生成模型在 ImageNet 256×256 基准上取得了 2.08 gFID。此外，利用四叉树结构保留的强空间相关性，QuadTok 生成器实现了零样本空间可控图像生成能力。代码：https://github.com/myc634/QuadTok。

## Abstract
We introduce QuadTok, a novel framework for visual tokenization and autoregressive image generation. Compared to traditional approaches using 2D grids or 1D token sequences, we propose a hierarchical quadtree structure, bridging the gap between 2D spatial binding and 1D sequence-level flexibility. The QuadTok tokenizer dynamically allocates representational capacity to visually intricate areas while leaving homogeneous regions at a coarse resolution. Compared with a fixed 256-token grid, our ImageNet-trained tokenizer saves approximately 10% of tokens on ImageNet and 9% when transferred zero-shot to the COCO dataset, while maintaining comparable reconstruction fidelity. Furthermore, the natural causality introduced by the tree structure seamlessly enables autoregressive image generation. Conditioned on a quadtree topology supplied before generation, our 947M GPT-style generative model achieves a 2.08 gFID on the ImageNet $256 \times 256$ benchmark. Additionally, leveraging the strong spatial correlation preserved by the quadtree structure, the QuadTok generator enables zero-shot spatially controlled image generation capabilities. # QuadTok 论文中文总结

## 1. 核心问题与整体含义

- **研究动机**：自然图像的空间信息密度高度非均匀——包含复杂纹理和高频模式的区域携带的信息远多于平滑或同质区域。理想的分词器应按局部复杂度分配表征容量。
- **现有方法的两难困境**：
  - **2D 网格分词器**（VQ-VAE、VQ-GAN、LlamaGen）：将图像压缩为刚性 2D 网格，token 预算固定且均匀分配，导致复杂区域表征不足、简单区域 token 冗余。
  - **1D 序列分词器**（TiTok、FlexTok、One-D-Piece、GigaTok）：支持可变长度、灵活性强，但 token 分配沿序列维度而非图像平面进行，空间感知能力弱，token 与图像块缺乏显式对应，损害像素级保真度与空间定位能力。
- **整体含义**：QuadTok 提出分层四叉树结构，在保留 2D 空间绑定的同时引入 1D 序列灵活性，按视觉复杂度动态分配 token，并利用树结构的天然因果性无缝支持自回归生成与零样本空间布局控制。

## 2. 方法论

### 2.1 核心思想
用四叉树递归划分图像空间，每个节点对应一个空间区域并作为一个视觉 token。节点以属性元组 (l, p) 定义（l 为树层级，p 为空间索引），通过广度优先搜索（BFS）序列化为 1D 序列，自然对齐粗到细的生成顺序。默认配置为两层（8×8 → 16×16），也评估三层扩展。

### 2.2 图像编码
- 用 ViT 编码器提取稠密特征 F ∈ R^{N×D}。
- 每个节点由可学习指令 token 表示：q_i = Emb_{l_i}(p_i)，编码空间位置与树层级。
- Aggregator Transformer 处理拼接序列 [F ∥ Q]，输出节点连续表征 Z。

### 2.3 向量量化与层级解码
- 量化：Quant(z_i) = argmin_{e_k∈C} ‖z_i − e_k‖₂，共享码本 V=16384、维度 d=8。
- 解码时组合 token 嵌入与指令嵌入：z̃_i = e_{y_i} + q_i。
- 层级聚合重建：H_{l+1} = F_up_{l+1}(H_l) + C_{l+1}，其中 C_l 为各层级反拼贴特征图，H_0 = 0，最终投影到 RGB。

### 2.4 树结构采样
训练时随机采样子树：所有 level-1 节点始终保留，每个父节点以概率 γ（默认 0.5）独立扩展为四个子节点，使模型对可变树结构鲁棒。

### 2.5 Kinship Causal Attention（亲属因果注意力）
保持四叉树层级拓扑，三条规则：
- **Parent ↔ Parent**：粗层 token 双向注意力，建立全局布局。
- **Child → Parent**：细层 token 可关注所有父 token，父 token 不可关注子 token。
- **Child ↔ Sibling**：细层 token 仅关注共享同一父节点的兄弟节点。

该规则可扩展至更深树：节点可关注所有更粗层级节点及同层兄弟节点，但不能关注更细层级节点。

### 2.6 Region-Wise Complexity Guided Tokenization（区域复杂度引导分词）
- 随机扩展一半粗区域形成探测树，另一半形成互补树，使每个区域同时出现在扩展与折叠状态。
- 计算空间 LPIPS 损失图，估计区域重建收益：b_r = AvgPool_r(E_collapsed_r − E_expanded_r)。
- b_r > τ 的区域扩展为四个子节点，默认 τ=0.05，采用 LPIPS 指标。

### 2.7 四叉树自回归生成
- 给定生成前提供的拓扑 T，自回归分解：p(Y|c, T) = ∏_{i=1}^{M} p(y_i | y_{<i}, c, t_{≤i})。
- 使用 LLaMA 风格 decoder-only Transformer + 标准因果掩码；结构指令嵌入编码树层级与空间位置。
- 推理时按 BFS 顺序生成：粗 token 先建立全局结构，细 token 逐步精修局部细节。

## 6. 主要结论与发现

- **重建**：QuadTok 在 ImageNet 上以平均 230 token 达到 rFID 1.46、PSNR 20.37，相比固定 256-token 网格节省约 10% token；零样本迁移到 COCO 用 232 token 节省约 9%。三层版本达到 rFID 0.770、PSNR 23.31（989 token）。
- **生成**：947M 生成器在 ImageNet 256×256 上取得 gFID 2.08，优于 1.4B RandAR-XXL（2.15），并与更大规模离散 token 生成器竞争。
- **扩展性**：生成器在不同模型规模上表现出一致的 scaling 行为；三层树在重建与生成上均验证有效。
- **零样本空间控制**：在冻结的 ImageNet 训练模型上，指定布局可将主体命中率提升最多 +28.7 个百分点（Grad-CAM），FID-50cls 变化仅 −0.15 至 +0.12。
- **消融发现**：
  - 去掉 Kinship Mask 后 rFID 略降（1.46→1.41）但 PSNR 降超 1 点（20.37→19.16），gFID 从 2.23 升至 3.17，说明空间结构 token 对 AR 生成至关重要。
  - 引导策略以 230 token 匹配 Full 树（320 token）的重建保真度，节省 28% token；随机树同规模下 rFID 更差（1.60）。
  - LPIPS 作为探测指标优于 MSE 与线性组合；τ=0.05 最佳。

## 7. 优点

- **结构创新**：四叉树巧妙桥接 2D 空间绑定与 1D 序列灵活性，兼顾空间对应与变长 token。
- **因果性天然契合 AR 生成**：BFS 顺序 + 树层级提供粗到细的生成先验，无需额外设计生成顺序。
- **Kinship Causal Mask 设计精巧**：通过父子/兄弟注意力约束，既保持层级信息流，又实现空间隔离，为定位控制奠定基础。
- **自适应分配有数据驱动依据**：Region-Wise Complexity Guidance 用互补探测树 + LPIPS 收益估计，效率高且可解释。
- **零样本空间控制**：无需布局特定训练即可实现主体位置控制，展示了结构化表征的实用价值。
- **消融完整**：对掩码、引导策略、指标、阈值均做了系统消融，并分析了空间隔离性。

## 8. 不足与局限

- **规模与模态限制**：仅限 ImageNet 类别条件生成，未扩展至 LAION 等大规模开放域数据集，也未支持文本到图像（text-to-image）合成；跨注意力机制与开放词汇文本条件尚需更多算力。
- **数据集偏差**：ImageNet 以物体为中心、单主体为主，限制了零样本空间控制的上限；复杂多物体场景与精细关系布局仍具挑战。
- **生成质量仍有差距**：gFID 2.08 落后于连续 token 的 xAR-H（1.24）、FlowAR-H（1.65）等，离散 token 路线的上限问题未被完全解决。
- **预分词开销**：自适应分配引入图像相关的树搜索，预分词延迟明显高于固定编码（8.795 ms vs LlamaGen 2.927 ms @ batch 32），虽可在训练数据准备阶段摊销，但仍是额外成本。
- **算力透明度不足**：未报告训练总 GPU 数量与时长，难以评估方法的总计算代价。
- **公平性边界**：多数对比为系统级比较，训练/采样设置不同；与连续 token 方法的同条件对比缺失。
- **三层结构 token 预算激增**：三层版本平均约 989 token（512 分辨率下达 1,021），相比两层版本 token 数大幅上升，效率优势减弱。
