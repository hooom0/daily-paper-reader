## 摘要
稀疏视图新视图合成是三维内容创建中的核心问题，但基于扩散的方法仍受限于迭代去噪，导致多视图生成在推理时成本高昂。我们提出 NAMVIS，一个无扩散框架，将多视图图像合成重新表述为几何条件化的下一尺度自回归。NAMVIS 不通过重复去噪生成目标视图，而是通过少量从粗到细的尺度步骤预测离散视觉 token，同时并行采样每个尺度内以及跨目标视图的所有 token。为了将这一生成过程锚定到显式相机几何，我们提出多尺度投影位姿编码，它在每个分辨率下将源相机和目标相机变换注入目标视图自注意力与源到目标交叉注意力。NAMVIS 进一步将全局条件与稠密几何感知交叉注意力相结合，使模型能够保持源视图外观，同时维持目标视图一致性。在 Objaverse、GSO 和 OmniObject3D 上，NAMVIS 在 PSNR、SSIM 和 LPIPS 上优于基于扩散的基线，同时在相同评估设置下比所评估的扩散基线快 3 倍以上。这些结果表明，几何条件化的下一尺度自回归是稀疏视图多视图合成中一种有前景且高效的扩散替代方案。更多定性结果、视频和资源见 https://corl-team.github.io/namvis/

## Abstract
Sparse-view novel view synthesis is a central problem in 3D content creation, but diffusion-based approaches remain limited by iterative denoising, making multi-view generation expensive at inference time. We introduce NAMVIS, a diffusion-free framework that reformulates multi-view image synthesis as geometry-conditioned next-scale autoregression. Instead of generating target views through repeated denoising, NAMVIS predicts discrete visual tokens through a small number of coarse-to-fine scale steps, while sampling all tokens within each scale and across target views in parallel. To anchor this generation process to explicit camera geometry, we propose Multi-scale Projective Pose Encoding, which injects source and target camera transformations into both target-view self-attention and source-to-target cross-attention at every resolution. NAMVIS further combines global conditioning with dense geometry-aware cross-attention, enabling the model to preserve source-view appearance while maintaining target-view consistency. Across Objaverse, GSO, and OmniObject3D, NAMVIS outperforms diffusion-based baselines in PSNR, SSIM, and LPIPS, while running over 3 times faster than the evaluated diffusion baselines under the same evaluation setting. These results suggest that geometry-conditioned next-scale autoregression is a promising and efficient alternative to diffusion for sparse-view multi-view synthesis. Additional qualitative results, videos, and resources are available at https://corl-team.github.io/namvis/

- **论文主张**：将多视图图像合成重新表述为**几何条件化的下一尺度自回归**（geometry-conditioned next-scale autoregression），用无扩散、粗到细、离散视觉 token 预测替代迭代去噪，从而在保持多视图一致性的同时显著提升推理效率。
- **整体含义**：NAMVIS 试图桥接“下一尺度自回归图像生成”和“3D 感知多视图生成”，证明自回归范式可作为扩散模型在稀疏视图多视图合成中的高效替代方案。

## 2. 方法论

### 2.1 核心思想

- 基于 Infinity / VAR 的 next-scale autoregressive 框架，将目标视图生成为多个由粗到细尺度上的离散视觉 token。
- 不进行迭代去噪，而是通过少量尺度步骤自回归解码；**同一尺度内、跨所有目标视图的 token 并行预测**，后续尺度条件于先前尺度。
- 以源图像视觉特征和源/目标相机几何作为条件，替代文本条件，驱动预训练自回归图像先验生成新视图。

### 2.2 关键技术细节

- **训练设置**：
  - 从同一场景采样源视图和目标视图，共享冻结的 VQ-VAE 编码器将源图、目标图编码为连续特征图。
  - 仅对目标计算多尺度残差 token maps，尺度 k 的连续特征由前 k 个上采样残差累加得到。
  - 保留 Infinity 的 bitwise 表示：每个 token 量化为二值码，transformer 用多个二分类器独立预测，并采用 bitwise 自校正稳定训练。

- **自回归目标**：
  - 建模 \(p_\theta(r^{tgt}_{1:K} \mid f^{src}, P^{src}, P^{tgt}) = \prod_{k=1}^K p_\theta(r^{tgt}_k \mid r^{tgt}_{<k}, f^{src}, P^{src}, P^{tgt})\)。
  - 使用尺度重加权交叉熵损失优化独立 bit 预测。
  - 训练时以 10% 概率丢弃源条件，替换为可学习无条件嵌入，以支持 classifier-free guidance（CFG）。

- **多视图序列布局与掩码**：
  - 将 N 个目标视图按尺度交错为序列 \(S=(S_1,\dots,S_K)\)，每个 \(S_k\) 包含所有视图在尺度 k 的扁平 token。
  - 使用 block-causal attention mask：尺度 k 的 token 可关注所有视图的 \(S_{\le k}\)，但不能关注 \(S_{>k}\)；同一尺度块内不同视图可自由互相注意。
  - 加入可学习的尺度级嵌入，帮助模型区分当前分辨率。

- **多尺度投影位姿编码（Multi-scale Projective Pose Encoding）**：
  - 基于 ProPE，将每个注意力头拆为投影部分和两个局部 rotary 部分。
  - 对视图 v、尺度 s，投影-RoPE 变换为：
    - query 分支：\(M_q(P_v)=P_v^\top\)
    - key/value 分支：\(M_{kv}(P_v)=P_v^{-1}\)
    - output 分支：\(M_o(P_v)=P_v\)
  - 投影部分注入 3D 相机几何，两个 RoPE 部分保持当前自回归分辨率下的局部 2D 布局。
  - **目标自注意力**：query、key、value、output 均使用目标视图相机，鼓励生成视图间一致性。
  - **源到目标交叉注意力**：query 和 output 使用目标相机，key/value 使用源相机，把生成锚定到带位姿的源观测。
  - 源特征保持稠密 VQ-VAE 分辨率，不降采样到当前目标尺度，使最粗尺度也能访问高分辨率源证据。

- **图像条件：全局路径 + 稠密路径**：
  - **全局路径**：可学习 query 对源特征做 cross-attention，得到 [SOS] token；该 token 前置到目标序列，并通过映射网络产生 AdaLN 的 scale/shift 参数，调制每个 transformer block。多目标视图时复制 [SOS]。
  - **稠密路径**：每个 transformer block 对未池化的 VQ-VAE 源特征做几何调制的 dense cross-attention，保留高频空间细节。
  - 该双路径设计同时保留源视图的低频语义外观和高频空间细节。

- **推理与缓存**：
  - 推理为无去噪的粗到细 K 步解码，尺度内和跨目标视图并行。
  - 使用标准 KV caching，并引入全局 ProPE caching：对每个源-目标相机配置和自回归尺度只计算一次 ProPE 投影张量，跨 transformer 层复用，降低几何感知注意力开销。

## 3. 实验设计

- **训练数据集**：
  - 在 Objaverse-XL 的过滤子集上训练。原始数据经三阶段过滤：去除渲染失败、前景覆盖率低、纹理缺失/过白、几何伪影严重资产；用美学质量模型筛选；生成 caption 并去除退化 caption。

## 4. 资源与算力

- **模型规模**：
  - NAMVIS 使用 1B 参数 transformer，初始化自 Infinity 2B checkpoint。
  - 保留每隔一个 transformer block，最终 **16 个 block，hidden dim 2048，16 个 attention head**。
  - VQ-VAE 预训练并冻结，仅训练自回归 transformer。

- **训练超参**：
  - AdamW，基础学习率 \(1\times10^{-4}\)，全局 batch size 512。
  - 20 个 warm-up epoch，随后 cosine learning-rate decay。
  - 总计训练 **500 epochs**。
  - 训练时源条件丢弃概率 0.1。

- **推理硬件**：
  - 推理时间在 **单张 NVIDIA A40 GPU** 上测量，256×256 分辨率。
