LyapuFlow: Controlling Generative Flows with
Lyapunov Feedback for Inverse Problems
Minseon Gwak1,4, Hans Hao-Hsun Hsu1,2,
Danielle C. Maddix3,∗, N. Benjamin Erichson1,4
1Lawrence Berkeley National Lab, 2Georgia Institute of Technology, 3Siemens, 4International Computer

Abstract
Pretrained flow models are now widely used as generative priors in science and vision, where
inference-time guidance enables test-time constraints without retraining. Existing methods
use projection, posterior sampling, or iterative optimization of the generative trajectory. We
propose LyapuFlow, an alternative based on Lyapunov feedback control. At each sampling
step, LyapuFlow predicts the terminal sample towards which the current flow is evolving,
and evaluates the constraint violation on this prediction. Then, we compute the minimum-
norm control that satisfies a prescribed Lyapunov decrease condition. The resulting control
remains inactive when the uncontrolled dynamics already reduce the constraint violation
at the prescribed rate. Otherwise, it provides a corrective update within a feedback trust
region that prevents the control from dominating the pretrained dynamics. We demonstrate
LyapuFlow in both data and latent spaces, outperforming alternatives spanning different
mechanisms for test-time constraint enforcement in scientific machine learning and image
inverse problems.

Introduction
Flow matching has emerged as a flexible framework for modeling complex data distributions [Lipman
et al., 2023]. In many downstream applications, the quality of generated samples critically depends on
whether they satisfy task-specific constraints. In scientific domains, for example, generated solutions to
partial differential equations (PDEs) need to be consistent with hard physical requirements, including
initial condition and conservation law. In image inverse problems, generated samples must reproduce
measurements degraded by a forward operator. Conditional generative models can incorporate constraints
available during training [Tong et al., 2024, Keegan and Ruthotto, 2026], but constraints specified at
inference time motivate test-time constrained generation, where the sampling trajectory of a pretrained
model is steered to satisfy the specified constraints.

optimization or online guidance [Daras et al., 2024]. Iterative trajectory optimization repeatedly integrates

without iterative optimization. Our main contributions are as follows:
• We introduce LyapuFlow, a test-time feedback controller for pretrained flow models. LyapuFlow
predicts the terminal sample from each intermediate state and computes a closed-form minimum-norm
feedback from a prescribed Lyapunov decrease condition (see Section 3).
• We characterize how the continuous-time feedback behaves under finite-step integration and introduce a
feedback trust region to limit overly large corrections (see Section 3.1). We further extend LyapuFlow to
latent-space models by propagating constraint gradients through the decoder and optionally restoring
the velocity-Jacobian contribution for finer-scale refinement (see Section 3.2).

Background and Related Work
In this section, we review existing approaches for enforcing a general equality constraint h(x) = 0. As
illustrated in Fig. 1, h varies across domains, ranging from physical constraints in PDEs to measurement-
consistency constraints in image inverse problems. Below, we examine how existing methods for steering
generative trajectories toward these constraints differ in their mechanisms.
Projection-based enforcement. Projection methods explicitly correct generated samples toward the
constraint set [Hansen et al., 2023, Christopher et al., 2024]. For a differentiable residual h : Rd →Rm,
consider the local linearization of the constraint h(x) + Jh(x)∆x = 0, where Jh = ∂h/∂x. Assuming
Jh has full row rank (typically with d > m), the minimum-norm correction is

ECI sampling applies constraint corrections to an extrapolated endpoint using a problem-specific
correction operator and interpolates the corrected endpoint with x0 for the next sampling step [Cheng
et al., 2025]. PCFM extends projection-based correction to differentiable nonlinear equality constraints
using Jacobian-based Gauss–Newton updates [Utkarsh et al., 2026, 2025]. For nonlinear constraints,
Eq. (2) requires solving an m × m linear system at each projection, which severely limits scalability.
Posterior and gradient-based guidance. Another method class guides generation using likelihood
or task-objective gradients. For a measurement y ∈Rm, posterior sampling targets
p(x1 | y) ∝p1(x1)p(y | x1),
(3)
where p1 denotes the pretrained generative distribution and p(y | x1) denotes the measurement likelihood.
DPS approximates sampling from Eq. (3) by estimating the measurement-likelihood gradient to guide
the reverse diffusion process [Chung et al., 2023]. FlowChef applies efficient task-objective guidance
to rectified flow models, while avoiding backpropagation through the velocity model [Patel et al.,
2025]. FlowDPS extends posterior guidance to flow models using measurement-likelihood gradients
at estimated clean states, likewise bypassing the velocity-model Jacobian [Kim et al., 2025]. ProFlow
similarly refines terminal estimates to improve physical consistency in PDE problems [Yu et al., 2026].
These methods steer the trajectory without explicit projection onto the constraint set, but suitable
guidance scales can vary widely across tasks.
Control and trajectory optimization. Control theory provides another approach to modifying
pretrained generative dynamics. FlowGrad and OC-Flow iteratively refine a complete sequence of control
inputs to improve the terminal objective [Liu et al., 2023, Wang et al., 2024]. OC-Flow formulates this
refinement as an optimal control problem and solves it using Pontryagin’s Maximum Principle [Pontryagin,
1987], balancing terminal loss and control cost:

LyapuFlow: Lyapunov Feedback for Constrained Generation

excessively large corrections to the generative dynamics. The main difficulty is that the control acts
on intermediate states xt, whereas the constraint is defined only on the terminal sample x1. Figure 2
provides an overview of the LyapuFlow sampling, illustrating how terminal constraints are propagated
to intermediate states while the feedback remains tied to the pretrained generative dynamics.

Experimental Results

generation in data space and image inverse problems in latent space. For comparison, we consider
several representative baselines for test-time constrained generation, including DPS [Chung et al., 2023],

et al., 2025], and OC-Flow [Wang et al., 2024]. DPS denotes its flow-based variant, which differen-
tiates through the velocity model. We also compare to efficient low-iteration (analysis is provided
in Appendix C.4) latent-space-oriented baselines (FlowChef [Patel et al., 2025] and FlowDPS [Kim
et al., 2025]). See Appendix B for experimental details on the PDE experiments and Appendix C
for the image experiments, including datasets, pretrained models, constraint definitions, evaluation
metrics, baseline configurations, and hyperparameters.

4.1
Physics-Constrained Generation
We first consider PDE solution generation, where a pretrained flow is guided to satisfy hard physical
requirements not explicitly imposed during training. In this setting, high likelihood under the learned
data distribution does not by itself guarantee physical validity. Following ECI [Cheng et al., 2025] and
PCFM [Utkarsh et al., 2025], we test on four PDE benchmarks: 1D Heat, 1D Burgers, 1D Reaction–
Diffusion (RD), and 2D Navier–Stokes (NS). The benchmarks span smooth diffusive dynamics to
evolution with sharp discontinuities. The evaluated constraints include initial conditions (IC), linear
conservation laws (CL), nonlinear conservation laws (NCL), and nonlinear dynamics (ND) based on
the Godunov update. Performance is assessed in terms of both constraint error (CE) and fidelity of
the resulting conditional solution distribution (See Appendix B.3 for metrics.).
Table 1 shows that LyapuFlow achieves the best MMSE/CMMSE across all four tasks and the best SM-
SE/CSMSE and FPD on three tasks. LyapuFlow achieves zero or near-zero CE across all tasks, including
Burgers after three final projection steps, while the baselines still exhibit non-negligible constraint error
under the same projection budget. The main distinction is in sample fidelity, where LyapuFlow more
accurately recovers the distribution associated with the specified physical conditions. Figure 3 illustrates
this behavior for Burgers: among the baselines, only LyapuFlow and DPS recover the localized shock

Image Inverse Problems
We next consider image inverse problems with measurement-consistency constraints. Given a degradation
operator A and noisy measurement y, we define h(x) = A(x)−y, so that satisfying h(x) = 0 corresponds
to measurement consistency. We test ×4 super-resolution, Gaussian deblurring, and motion deblurring
across AFHQ, FFHQ, and DIV2K datasets using a pretrained latent flow model, Stable Diffusion
3.5-Medium [Esser et al., 2024]. This setting tests whether LyapuFlow can impose data consistency
while preserving the instance-specific structure of the underlying image.
Table 2 compares reconstruction quality across the three inverse problems under a matched 28-NFE
budget. LyapuFlow achieves the best or second-best performance across metrics, including the best
SSIM and LPIPS throughout. This is achieved with a single feedback update per flow step, without
iterative inner optimization. Figure 4 shows the same trend qualitatively. In super-resolution, FlowDPS
introduces antenna-like structures on the butterfly that are absent from the target image, while in
motion deblurring it produces a hazier reconstruction and removes distinctive markings around the
cat’s mouth. These examples suggest that measurement guidance can produce plausible reconstructions
while losing instance-specific details. LyapuFlow better preserves these structures while maintaining
measurement consistency. See Appendix C.5 for additional results.

4.3
Ablation Studies
Role of LyapuFlow Components. We isolate two components of the feedback construction: the
explicit time derivative and the feedback trust region. Table 3 shows that removing the time-derivative
term consistently degrades fidelity on Burgers and NS (with full tables in Appendix B.5), consistent with
its role in tracking how the predicted terminal constraint changes along the flow. Empirically, removing
the trust region generally degrades performance, consistent with its role in limiting large finite-step
corrections. See Appendix C.5 for ablations on the gradient switch step ksg.
Hyperparameter Sensitivity. We compare LyapuFlow and DPS through their principal guidance
parameters. DPS directly tunes a step size ηDPS, whereas LyapuFlow uses the decay rate α to determine
the required feedback. Figure 5 shows that the preferred DPS step size varies substantially across
PDEs, with larger values helping NS but degrading Heat, Burgers, and RD. LyapuFlow is more stable
across the tested values of α, suggesting lower sensitivity to task-specific dynamics. Extended results
for all samplers are provided in Appendix B.6.
NFE Budget. We first test whether the reconstruction gains persist as the integration budget increases.
Figure 6 compares FlowDPS and LyapuFlow at 28 and 40 NFEs. Increasing the budget removes some
FlowDPS artifacts, but does not recover instance-specific details lost during reconstruction. In the
first row, facial freckles remain substantially weakened at both budgets, while in the second row the
eyelid crease remains absent. LyapuFlow preserves these structures at both budgets. The additional
10


evaluations at 40 NFEs in Appendix C.5 show the same overall trend, indicating that the difference
is not explained only by the number of integration steps.
5
Conclusion
We propose LyapuFlow, a test-time control framework for enforcing constraints on pretrained generative
flows through Lyapunov feedback. By evaluating constraint violations on predicted terminal samples,
LyapuFlow computes state-dependent corrections that are activated only when the pretrained dynamics
fail to provide sufficient Lyapunov decrease. A feedback trust region further limits the control magnitude
to reduce excessive finite-step corrections and the resulting discretization error. We demonstrate the
approach in both data and latent spaces across scientific machine learning and image inverse problems.
LyapuFlow consistently achieves strong constraint satisfaction and high sample fidelity relative to
alternative test-time constraint-enforcement strategies.
Limitation. A current limitation is that LyapuFlow relies on differentiable constraint functions to
construct the feedback signal. This restricts its direct applicability to constraints for which gradients
with respect to the generated sample can be obtained. Extending LyapuFlow to non-differentiable,
discrete, or black-box constraints is an interesting direction for future work. In addition, the proposed
feedback introduces additional computational and memory overhead during generation. Combining
LyapuFlow with acceleration techniques [Gupta et al., 2026, Nie et al., 2026] is therefore another
promising direction for future work.

Generative Backbone
We use unconditional functional flow matching (FFM) backbones [Kerrigan et al., 2023] so that the
physical conditions imposed at test time are not available to the generative model during training. Each
PDE-specific model uses an Fourier neural operator (FNO) [Li et al., 2020] to learn a velocity field
vθ(x, t) that transports a functional prior x0 ∼p0 to a solution x1 ∼pdata. For t ∼U(0, 1), training uses

Initial conditions, boundary conditions, and forcings are not provided as explicit conditioning channels.
The backbone instead models the distribution of complete solution fields induced by their variation.
The Heat, Burgers, and RD models use four Fourier layers, while the NS model uses two. For Heat,
Burgers, and RD, p0 is a Matérn Gaussian-process prior with length scale 0.001 and variance 1; NS uses
an i.i.d. Gaussian prior. Heat, Burgers, and RD are trained with Adam using learning rate 3 × 10−4,
batch size 256, and 20k optimization steps. NS is trained with AdamW using the same learning rate,
batch size 24, and 500k optimization steps.

C
Image Inverse Problems
This section provides the complete experimental setup and additional results for latent-space image
inverse problems. We first describe the datasets, pretrained backbone, degradation operators, baseline
configurations, and evaluation protocol. We then examine sampling efficiency, performance at a larger
integration budget, frequency-domain behavior, and additional qualitative reconstructions.
C.1
Experimental Setup
C.1.1
Datasets and Backbone
We evaluate on 1k AFHQ images, comprising 0.5k dog and 0.5k cat images, 1k FFHQ images, and
0.8k DIV2K images, all at 768 × 768 resolution. All methods use Stable Diffusion 3.5-Medium [Esser
et al., 2024] as the pretrained latent-space flow model with classifier-free guidance scale 2 [Ho and
Salimans, 2022]. AFHQ uses the prompts “a photo of a dog” and “a photo of a cat”, FFHQ uses “a
photo of a person,” and DIV2K uses “a high quality photo of {DAPE tags}”, with the tags extracted
from the DAPE-degraded images [Wu et al., 2024].
C.1.2
Inverse Problems and Observations
We consider ×4 bicubic super-resolution, Gaussian deblurring, and motion deblurring with kernel size 61.
For each task, the observed image is obtained by applying the corresponding forward operator and adding
measurement noise with σn = 0.03. The resulting observation defines the test-time data-consistency
constraint. The same pretrained latent flow is therefore reused across all inverse problems, while only
the observation operator and measurement change at inference time.
C.2
Baselines and Evaluation Protocol
We consider LatentDAPS [Zhang et al., 2025], FlowChef [Patel et al., 2025], FlowDPS [Kim et al.,
2025], FLAIR [Erbach et al., 2026], and FlowLPS [Park and Ye, 2025] as candidate baselines. The
primary main-text comparison focuses on FlowChef and FlowDPS because, like LyapuFlow, they operate
without the much larger inner optimization loops used by several of the other methods. We report the
computational cost of all candidate baselines separately in Appendix C.4.
Method-Specific Settings.
• LatentDAPS [Zhang et al., 2025]. 20 EDM annealing steps from σ = 1 to 0.2 with ρ = 7; each
interval uses two-step midpoint denoising, for 40 total NFEs. Non-SR tasks use 15 Langevin MCMC
updates per annealing step with learning rate 10−4. Super-resolution uses 60 updates with learning
rate 10−3, decayed by 0.7 every 5 MCMC updates; τ = 0.03.
• FlowChef [Patel et al., 2025]. One data-consistency update per flow step with step size 15.
• FlowDPS [Kim et al., 2025]. Three data-consistency updates per flow step with step size 15.
• FLAIR [Erbach et al., 2026]. Official repository defaults with 15 data-term updates per step,
data-term SGD learning rate 1.0 for super-resolution and 0.1 for deblurring, regularizer scale 0.5, the
bundled calibration schedule, and tmin = 0.18.
• FlowLPS [Park and Ye, 2025]. NL = 5 Langevin and NP = 10 proximal-SGD updates. The
Langevin step size is 10−4, the proximal-SGD learning rate is 0.1 without decay, the schedule offset is
3, and pCN re-noising is used.
• LyapuFlow. See Table 10.

C.3
Evaluation Metrics
We report peak signal-to-noise ratio (PSNR) and structural similarity index (SSIM) to measure re-
construction distortion and structural agreement. We additionally report Learned Perceptual Image
Patch Similarity (LPIPS) and Fréchet Inception Distance (FID) to capture perceptual and distributional
differences that are not fully reflected by pixel-space distortion.
C.4
Sampling Efficiency
The candidate image baselines differ substantially in the amount of computation performed within each
sampling step. Table 11 compares reconstruction quality and runtime on a small evaluation subset. The
iteration-heavy methods LatentDAPS, FLAIR, and FlowLPS incur substantially greater sampling cost
than single-update methods. For example, FlowLPS improves PSNR over LyapuFlow by 1.21 dB on mo-
tion deblurring while requiring more than 8× longer sampling time. This motivates the primary main-text
comparison with FlowChef and FlowDPS, which operates in a more comparable quality–efficiency regime.
