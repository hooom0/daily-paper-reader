## 摘要
文本到图像扩散Transformer（DiT）是强大的生成器，但直接提示为风格强度提供的控制接口有限，并且可能无法抑制不想要的概念。为了实现这些控制，我们提出了 AcFlow，一种推理时控制器，它通过学习到的概念条件速度场来传输中间层图像 token 激活，同时保持基础 DiT 冻结。文本概念描述指定所需的干预，而积分时域提供连续控制参数。该场产生随 token 变化且依赖于激活的更新。由于参数在每个任务族内的概念之间共享，该场支持细粒度描述，并能泛化到训练期间未见过的概念，而无需针对每个概念进行拟合。在风格控制方面，AcFlow 在高风格对齐情形下，在所评估的基线中实现了最佳的风格—内容权衡。在固定操作点，AcFlow 达到的风格—内容对齐为 0.5365/0.2860，而风格对齐最高的基线为 0.4397/0.2684。定性结果展示了多种概念的抑制，包括直接提示失败的情况。我们的分析支持将学习到的速度场视为一种自适应控制机制，其中更新方向随 token 变化，并取决于其激活状态。我们的代码可在 https://github.com/Nove1yst/AcFlow 获取。

## Abstract
Text-to-image diffusion transformers (DiTs) are powerful generators, yet direct prompting provides limited control interface for style intensity and can fail to suppress unwanted concepts. To enable these controls, we introduce AcFlow, an inference-time controller that transports intermediate layer image-token activations through a learned concept-conditioned velocity field while keeping the base DiT frozen. A textual concept description specifies the desired intervention, while the integration horizon provides a continuous control parameter. The field produces token-varying, activation-dependent updates. With parameters shared across concepts within each task family, the field supports fine-grained descriptions and generalizes to concepts unseen during training without per-concept fitting. On style control, AcFlow achieves the best style--content trade-off among the evaluated baselines in the high-style-alignment regime. At a fixed operating point, AcFlow attains style--content alignment of 0.5365/0.2860, compared with 0.4397/0.2684 for the baseline with the highest style alignment. Qualitative results demonstrate suppression of diverse concepts, including cases where direct prompting fails. Our analyses support the learned velocity field as an adaptive control mechanism, with update directions varying across tokens and depend on their activation states. Our code is available at https://github.com/Nove1yst/AcFlow.

# AcFlow 论文中文总结

## 1. 核心问题与研究动机

- **背景**：文本到图像扩散 Transformer（DiT，如 FLUX.1-dev）生成能力强，但**直接提示（prompting）不是精确的控制接口**。
  - 风格强度无法平滑调节：加入 "weak / strong" 等修饰词往往得到强度相近的结果，缺乏校准的控制轴。
  - 概念抑制失败：在提示中写 "no lighthouse" 常常仍会生成灯塔。
- **现有方案的不足**：
  - 参数级适配（Concept Sliders、Text Slider 等）需要**为每个新概念单独拟合**，可能影响非目标概念，且在连续修改时存在能力退化风险。
  - 激活干预方法（ICM、Semantic Steering、SHIFT、CASteer、DSAS 等）多使用**固定方向**或仅做**标量缩放**，方向不能随激活状态自适应；CAT 虽为非线性，但基于**均值池化激活并广播到所有 token**。
- **目标**：设计一个**推理时控制器**——基础生成器参数冻结，参数在各概念间共享，用户可用文本概念描述指定干预内容，并用一个显式参数连续控制干预强度。

## 2. 方法论

### 2.1 核心思想：把控制建模为激活空间中的流场

- 在冻结 DiT 的**单个 block** 上，取输出残差流状态 `h ∈ R^{S×d}`（S 为文本 + 图像 token 数）。
- 给定源提示 `p` 与概念描述 `c`，在固定去噪噪声水平 σ 下定义**概念条件速度场** `v_φ(h, t, c; σ)`，通过常微分方程生成流：
  - `d/dt φ_t(h) = v_φ(φ_t(h), t, c; σ)`，`φ_0(h) = h`
  - 干预后激活：`h' = φ_T(h) = h + ∫_0^T v_φ(...) dt`
- 数值上用 **N 步前向欧拉**离散化：`h^{(k+1)} = h^{(k)} + (T/N)·v_φ(h^{(k)}, kT/N, c; σ)`。
- **积分时域 T 是连续控制参数**：T = 0 时退化为未修改状态；注意流时间 t 与去噪噪声水平 σ 不同，σ 在每次激活流积分内固定，每个去噪步都从当前 block 输出重新开始积分。
- **与简化形式的关系**（体现一般性）：
  - 共享速度（均值池化 token）→ 所有 token 同一更新；
  - 标量 × 固定方向 → 固定概念方向加缩放；
  - 常数方向 → 标准加性干预 `h_i + T·d(c)`。
  - 完整场**同时放松了"共享 token 更新"和"固定概念方向"两个限制**。

### 2.2 只干预图像 token

- 单流状态 `h = [h_txt; h_img]`；文本 token 只能间接影响输出，图像 token 位于残差路径上、直接进入输出头，且两者来自不同模态、激活分布不同。
- 因此只做：`h' = [h_txt; φ^img_T(h_img)]`。
- **Token-swap 诊断**（FLUX.1-dev block 16，312 条 MegaStyle 提示）：图像 token 替换可恢复 93.4% 的目标风格增益，文本 token 仅 46.1%，两者均替换为 99.7%。

### 2.3 网络结构（FlowBlock）

- 采用一个与主干匹配的 Transformer 风格模块：
  - 通过**交叉注意力**提取概念信息：`Q = AdaNorm(h_img; e_flow(t) + e_c(c̄))`，`K = V = C = E_txt(c)`，`h̃ = h_img + g_t ⊙ CrossAttn(...)`。
  - 保留主干的注意力几何、QK 归一化、归一化位置与门控残差约定；唯一改动是把生成器的模型时间换成**流时间 t**。
  - 随后接一个原生风格 transformer block，由 `e_model(σ) + e_c(c̄)` 调制。
  - 速度输出：`v_φ(h_img, t, c; σ) = h_out − h_img`（残差即速度）。

### 2.4 训练：速度蒸馏

- 样本 `(z_0, p_src, p_tgt, c) ~ D`；构造 `z_σ = (1−σ)z_0 + σϵ`。
- **教师**：冻结模型在目标提示下的速度 `u_tgt = G_θ(z_σ, σ, p_tgt)`。
- **学生**：同一冻结模型在源提示下、在 block b 激活 AcFlow（条件 c、T=1）：`û = G_θ,φ(z_σ, σ, p_src, c, T)`。
- 损失：`L_vel(φ) = E[MSE(û, stopgrad(u_tgt))]`，只优化场参数 φ，主干与文本编码器全冻结。

## 6. 主要结论与发现

- **控制效果**：固定操作点下 ACFLOW 达到风格/内容对齐 0.5365/0.2860，优于风格对齐最高的基线 Mean-AcT（0.4397/0.2684）与 Concept Sliders（0.5109/0.2786）；在高风格对齐区间处于全局 Pareto 前沿。
- **零样本泛化**：在完全未见过的风格族上，T=2 时达到 0.442 风格 / 0.281 内容对齐，且仍保持对 T 的强度响应。
- **连续控制**：T 提供风格—内容权衡上的连续坐标；虽然训练只用 T=1，外推到 T>1 仍能增强风格（但风格增益最终饱和而内容对齐继续下降，故大 T 并非总更好）。
- **细粒度条件**：同一内容、同一风格族、同一 T 下，不同的细粒度描述（丝网印半调、光泽反射摄影、灰度线描、层叠剪纸）产生不同效果。
- **概念抑制**：可抑制多种概念（雾、灯塔、河流、牡丹、羽毛帽、雏菊等），包括直接提示失败的场景；中间 T 呈现部分抑制；但场景外观与构图也可能改变。
- **NSFW 抑制**：NudeNet 检出从 402 降至 73（s=2）与 38（s=3），同时 DINO-I2I 与 LPIPS 优于 CA、ESD-x、Negative Prompting；对抗攻击下 clean ASR 9.17%、攻击 ASR 25.7%（Union 43.1%），显著低于多数基线。
- **机制发现**：
  - Rank-1（共享轴）分量占位移能量约 76%/75%，但将其

- Rank-1（共享轴）分量占位移能量约 76%/75%，但将其**单独替换为固定方向**（能量匹配对照）后，风格/内容对齐明显劣于完整流场；说明**残差（非 rank-1）分量虽然能量占比小，却承载了随 token 与噪声水平变化的自适应方向信息**，正是完整流场相对固定方向/标量缩放基线的主要增益来源。
  - **噪声水平上的几何变化**：随去噪噪声水平 σ 从高到低，更新方向的 off-axis 能量占比、更新能量与 top-5% token 能量集中度均呈现系统性变化——高噪声阶段方向更分散、能量分布更均匀，低噪声阶段方向更集中、少数 token 主导更新。这解释了为何"固定方向 + 常数缩放"难以同时匹配不同去噪阶段的控制需求。
  - **Token-swap 因果诊断**（前述 93.4% / 46.1% / 99.7%）进一步支持"只干预图像 token"的设计选择：图像 token 是风格增益的主要承载者，文本 token 仅提供间接、部分的贡献。

## 7. 局限性与失败模式

- **风格增益饱和**：随 T 增大，风格对齐先升后饱和，而内容对齐持续下降；大 T 并不单调更优，需要用户在 Pareto 前沿上手动选取操作点。
- **概念抑制的场景副作用**：抑制目标概念时，场景外观与构图可能被一并改变（如光照、布局、材质），并非"只删概念、其余不动"的干净编辑。
- **抑制以定性为主**：除 NSFW 外，概念抑制缺少系统的定量指标表，跨概念的可比性依赖案例展示。
- **单 block 干预的容量边界**：场只在冻结主干的一个 block 上作用，对于需要跨层协调的复杂概念组合，表达能力可能受限。
- **训练依赖成对监督**：速度蒸馏需要 (源提示, 目标提示, 概念描述) 三元组，概念描述的覆盖度直接影响泛化；对训练分布外的新概念族，控制精度会下降。
- **算力信息缺失**：论文未报告 GPU 型号、数量与总训练时长，复现成本与规模化可行性难以评估。

## 8. 总体评价与贡献定位

- **方法层面的核心贡献**：把"激活干预"从**固定方向 / 标量缩放 / 均值池化广播**的一般形式，推广为**激活空间中的条件速度场 ODE**，并证明既有方法都是其特例。这一统一视角既解释了为什么简单加性干预在细粒度控制上不足，也给出了可训练、可连续调节的替代方案。
- **工程层面的贡献**：一个**共享的、推理时的、参数冻结主干**的控制器——单一组参数覆盖所有概念，用户仅通过文本概念描述与积分时域 T 指定"干预什么"与"干预多强"，避免了为每个新概念重新拟合。
- **实证层面的贡献**：在风格连续控制、概念抑制、NSFW 抑制三类任务上，跨 FLUX 与 Z-Image 两个主干，配合消融、机制分析与对抗鲁棒性评测，验证了方法的有效性、泛化性与可移植性。
- **可复现性**：训练超参、更新步数、评测协议与基线移植细节披露较充分；主要缺口是算力规模与概念抑制的定量指标。
- **定位**：ACFLOW 更接近一个**通用、轻量、可控的推理时控制层**，其价值不仅在于具体指标领先，更在于提供了一个可扩展的框架——速度场可以按任务、按概念、按主干替换，而控制接口（概念文本 + T）保持稳定。
