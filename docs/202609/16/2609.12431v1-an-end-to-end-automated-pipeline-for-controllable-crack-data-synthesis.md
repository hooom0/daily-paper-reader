## 摘要
自动裂缝检测日益依赖深度学习，但其可靠性受限于稀缺且可控性弱的缺陷数据。现有生成式增强方法通常将裂缝合成视为通用图像生成任务，对形态、边界保真度和场景上下文提供的控制不足。本文提出一种用于可控裂缝数据合成的端到端自动化流程，将裂缝几何与检测上下文形式化为可复用的计算约束。首先，利用GAN将程序化采样的贝塞尔曲线骨架转换为逼真的裂缝掩码，从而无需人工设计掩码即可可扩展地生成多样裂缝形态。其次，双ControlNet扩散框架将外观引导与几何引导解耦，并通过基于边缘的分支强制严格的边界一致性。该框架支持无背景合成和上下文感知修复。在CRACK500和CrackTree200上的实验表明，相较于现有增强基线取得了一致提升，展示了用于自动裂缝检测数据生成的可扩展工程信息学工作流。

## Abstract
Automated crack inspection increasingly relies on deep learning, yet its reliability is limited by scarce and weakly controllable defect data. Existing generative augmentation methods often treat crack synthesis as a generic image-generation task, offering insufficient control over morphology, boundary fidelity, and scene context. This paper proposes an end-to-end automated pipeline for controllable crack data synthesis that formalizes crack geometry and inspection context into reusable computational constraints. First, procedurally sampled Bézier-curve skeletons are translated into realistic crack masks using a GAN, enabling scalable generation of diverse crack morphologies without manual mask design. Second, a dual-ControlNet diffusion framework disentangles appearance guidance from geometric guidance, with an edge-based branch enforcing strict boundary consistency. The framework supports both background-free synthesis and context-aware inpainting. Experiments on CRACK500 and CrackTree200 show consistent gains over existing augmentation baselines, demonstrating a scalable engineering informatics workflow for automated crack-inspection data generation.

## 2. 方法论
- **核心思想**：先用程序化 Bézier 曲线骨架生成多样裂缝拓扑，再用 GAN 将其翻译为真实裂缝掩码；随后用双 ControlNet 扩散框架解耦“外观引导”和“几何引导”，并由边缘分支施加硬边界约束；支持无背景合成与上下文感知修复两种模式。
- **自动化掩码生成**：
  - 利用 CLIPasso 将真实裂缝二值掩码反向映射为 Bézier 曲线草图，自动构建“掩码—曲线”配对数据集。
  - 训练一个基于 Pix2PixHD 的 GAN，学习从简单 Bézier 线图到真实裂缝掩码的正向映射，加入厚度变化、不规则边缘和分支模式。
  - 可无限程序化生成 Bézier 曲线，再经 GAN 转成裂缝掩码，解决掩码多样性和自动化问题。
- **随机 Bézier 曲线生成算法**：
  - 输入曲线数量 N、阶数 d、空间策略 S、最大偏差比 ρmax、画布尺寸。
  - 端点采样策略：
    - `random`：端点从全图均匀采样，适合稀疏孤立裂缝。
    - `high`：端点限制在中心热区，促使曲线交叉，生成复杂网络。
  - 中间控制点沿端点基线单调推进，并施加受 ρmax 限制的垂直偏移，防止过度弯曲、自交和极端振荡。
  - ρmax 控制弯曲程度：小值接近直线，大值更蜿蜒但结构合理。
- **双 ControlNet 扩散框架**：
  - 基于 Stable Diffusion v1.5。
  - 两个并行空间条件：
    - `ControlNet-Crack`：可训练，输入 GAN 生成的裂缝掩码 Mc，提供裂缝位置、纹理、外观引导。
    - `ControlNet-Edge`：冻结预训练 lineart 模型，输入 Mc 的 Canny 边缘图 Me，提供严格几何边界约束。
  - 在第 i 个 U-Net 残差块中注入控制特征：
    - \(h'_i = h_i + w_c \cdot Z_c(f_{i,c}) + w_e \cdot Z_e(f_{i,e})\)
    - 其中 \(Z_c, Z_e\) 为零卷积层，\(w_c, w_e\) 为控制权重。
  - 最终噪声预测为 \(\epsilon_{pred} = \epsilon_\theta(z_t, t, c_y, M_c, M_e)\)。
  - 作用解耦：ControlNet-Crack 告诉模型“画什么”，ControlNet-Edge 告诉模型“画在哪里、边界多厚”。
- **两种生成模式**：
  - **无背景模式（Background-Free）**：文本提示 + 掩码 + 边缘条件，从噪声生成裂缝图像，适合大规模随机增强。
  - **修复模式（Inpainting）**：用户提供背景图 \(x_{bg}\)、修复掩码 \(M_i\)，并令 \(M_c = M_i\)；每一步去噪后将预测区域与加噪背景按掩码混合：
    - \(z_{t-1} = M_i \odot \tilde{z}_{t-1} + (1-M_i) \odot z_{bg,t-1}\)
  - 推理使用 DDIM，50 步，512×512，\(w_c=0.6\)、\(w_e=0.8\)，并用判别器按 mIoU ≥ 0.9 过滤生成样本。
