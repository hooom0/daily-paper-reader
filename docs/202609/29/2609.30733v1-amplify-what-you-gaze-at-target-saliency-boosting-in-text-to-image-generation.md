## 摘要
文本到图像生成在控制物体出现的内容、位置和方式方面已取得进展，但视觉注意力如何在物体之间分配仍很大程度上尚未被探索。本文提出目标显著性提升（Target Saliency Boosting），一项新任务，旨在文本到图像生成过程中增强特定物体的视觉显著性，且无需任何视觉先验。我们的关键洞见是，视觉显著性本质上是相对的：提升目标物体的显著性也取决于场景中所有物体的全局显著性分布。基于这一洞见，我们提出 GazeME，一个轻量级框架，使用显著性标记提示，在物体描述周围插入可学习的标记 token，以指示应视觉强调或抑制哪些物体。为学习这些标记，我们构建了一个显著性-语义数据集，将图像-提示对中的物体与物体级显著性分数关联起来，并提出显著性先验标记激活（SPMA），一种显著性感知的随机标记激活策略，利用相对显著性关系进行稳健训练。在推理时，GazeME 自动将适当的标记插入提示中，从而直接增强目标物体的视觉显著性。大量实验表明，GazeME 能有效提升目标显著性，同时保持语义对齐和图像质量。

## Abstract
Text-to-image generation has advanced in controlling what, where, and how objects appear, yet how visual attention is distributed among objects remains largely unexplored. In this paper, we introduce Target Saliency Boosting, a new task aimed at boosting the visual saliency of a specific object during text-to-image generation without requiring any visual priors. Our key insight is that visual saliency is inherently relative: boosting the saliency of a target object also depends on the global saliency distribution across all objects in the scene. Based on this insight, we propose GazeME, a lightweight framework that uses saliency-marked prompts, inserting learnable marker tokens around object descriptions to indicate which objects to visually emphasize or suppress. To learn these markers, we construct a saliency-semantics dataset that associates objects in image--prompt pairs with object-level saliency scores, and propose Saliency Prior Marker Activation (SPMA), a saliency-aware stochastic marker activation strategy that exploits relative saliency relationships for robust training. During inference, GazeME automatically inserts appropriate markers into the prompt, thereby directly enhancing the visual saliency of the target object. Extensive experiments demonstrate that GazeME effectively boosts target saliency while preserving both semantic alignment and image quality.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究空白**：文本到图像生成已能控制对象"生成什么、在哪里、以何种形态出现"，但"视觉注意力如何在对象之间分配"这一问题仍基本未被探索。语义保真只是视觉传播的起点，真正决定设计成败的是"什么最先抓住观看者的注意力"。
- **现实需求**：广告需让产品突出，故事插图需聚焦主角。显著性影响记忆保持、认知理解与情感共鸣。因此，将挑战从"语义"推进到"注意力动态"具有重要价值。
- **现有方法局限**：
  - 显著性预测工作（如 DeepGaze II、AAM）主要从已有图像预测注视点，属于正向问题；其逆问题——生成使指定目标显著的图像——几乎空白。
  - GazeFusion 虽以显式显著性图为条件引导生成，但要求用户手工指定显著性图，交互负担重。
  - 可控生成方法（ControlNet、GLIGEN、LoRA、注意力操控等）主要控制"内容/位置/外观"，对"注意力分布"支持有限。
- **核心洞见**：视觉显著性本质上是**相对**的——提升目标对象的显著性，取决于场景中所有对象的全局显著性分布，而非孤立地增强目标。
- **论文任务定义**：提出**目标显著性提升（Target Saliency Boosting）**，即在无需任何视觉先验的前提下，通过自然语言交互提升特定对象的视觉显著性，定义了一种"语言意图→视觉显著性"的新交互范式。

## 2. 方法论

### 2.1 核心思想

- 引入**显著性标记提示（saliency-marked prompts）**：在对象描述周围插入两对双向可学习标记 token——`<focus></focus>`（应被视觉强调）与 `<unfocus></unfocus>`（应被抑制）。
- 仅优化这四个标记的嵌入，冻结生成模型全部骨干参数，实现轻量化并保留预训练模型的泛化能力。
- 整体框架 GazeME 含三阶段：(a) 显著性-语义数据标注；(b) 标记嵌入高效学习；(c) 标记引导图像生成。

### 2.2 阶段一：显著性-语义数据标注

- 构建 **1,637 个图像-提示对**的数据集，每个样本为 `{I, P, {(o_i, s_i)}}`，其中 `s_i` 为对象 `o_i` 的显著性分数（该对象区域内平均显著性相对于全局分布）。
- 数据构建两步：
  1. **合成数据生成**：用 LLM（DeepSeek-V4-Flash）生成多样化提示及名词短语列表 → 用文本到图像模型（FLUX.1-dev）合成图像 → 用 SAM3 按自然语言概念分割对象掩码 → 过滤重复类别或无法检测的样本。
  2. **对象级显著性打分**：用 Attend-to-Anything Model（AAM）估计像素级显著性图 S；再基于掩码 M_i 适配标准化扫描路径显著性（NSS）公式计算对象级分数：
     - `s_i = (1/σ_S) * ( Σ_p S(p)·M_i(p) / |M_i| − μ_S )`
     - 其中 μ_S、σ_S 为整图显著性的均值与总体标准差，|M_i| 为掩码像素面积。分数越高越显著。

### 2.3 阶段二：标记嵌入高效学习（SPMA）

- 提出 **显著性先验标记激活（SPMA）**，一种轻量、显著性分数条件化的动态标记插入机制，将标记嵌入学习为"显著性关系"而非固定模式，形成对不同显著性方向和对象组合的隐式集成。
- SPMA 三步：
  1. **显著性分组**：以阈值 γ 将对象分为高/低显著性组，`y_i = 1` 若 `s_i ≥ γ`，否则为 0；γ 取每样本平均显著性分数。
  2. **随机标记激活**：为每个对象采样二元激活变量 `z_i ~ Bernoulli(p_i)`；高显著性对象用 `<focus>` 包裹，低显著性对象用 `<unfocus>` 包裹。概率设置：
     - 高显著性组：最显著对象恒激活（p=1）；其余对象 `p_i = (s_i − γ)/(s_i^up − γ)`，其中 `s_i^up` 为最近更高显著性分数。
     - 低显著性组：最不显著对象恒激活（p=1）；其余对象 `p_i = (γ − s_i)/(γ − s_i^down)`，其中 `s_i^down` 为最近更低显著性分数。
  3. **显著性一致性截断**：高显著性组中，某对象仅当所有更高显著性对象均激活时才保持激活，否则被停用；低显著性组反之。效果：越接近 γ 的对象越易被停用，越远离 γ 的越易被激活；相似显著性对象倾向共同激活；保持相对显著性排序，避免矛盾激活模式。
- **训练目标**：冻结其他参数，仅优化标记嵌入 θ，使用流匹配（flow matching）目标：
  - `L = E_{t,ε} [ ‖v_θ(x_t, t, P′) − u‖₂² ]`
  - 其中 `x_t` 为加噪后的图像隐表示，`u` 为目标速度，`v_θ` 为以显著性激活提示 `P′` 为条件预测的速度。

### 2.4 阶段三：标记引导图像生成

- 给定输入提示 `P_in` 和目标对象 `o_t`，用 LLM 识别提示中的其他对象 `O_other`。
- 构造显著性增强提示 `P*`：目标对象加 `<focus>`，其余对象加 `<unfocus>`，输入带已学习标记嵌入的生成模型，输出图像 `I_out`。
- **实现细节**：基座模型 FLUX.1-dev；AdamW，学习率 3×10⁻⁴；训练 2,000 步，batch size 2，单卡 NVIDIA H200，约 2 小时；推理分辨率 512×512，30 采样步，随机种子 42。

## 6. 主要结论与发现

- **定量结果**：GazeME 在 Target-NSS 上取得最高分（0.2761，基座模型 0.1791，最强基线 FLUX-Editing 0.2554）；CLIPScore（0.2820）与基座（0.2890）及基线处于相近区间，无明显语义退化；CLIPIQA（0.9516）达到最优水平。
- **定性结果**：GazeME 能一致地让目标对象成为主要视觉焦点，而其他方法往往同时放大其他对象或引入不自然伪影。
- **捷径分析**：FLUX-Editing 主要靠模糊背景；提示级方法倾向放大目标、向中心移动、提升亮度对比度；GazeME 在低层因素上的偏离最小且不集中于单一维度，说明其提升显著性主要来自**显著性重分配**，而非低层捷径。
- **消融结论**：
  - 去掉 SPMA，Target-NSS 从 0.2761 降至 0.2276；
  - 不训练标记（固定嵌入），降至 0.2192；
  - P* 中去掉 `<unfocus>`，降至 0.2521；
  - 说明 SPMA、标记训练、非目标抑制三者均关键。
  - γ 的不同设置下结果变化很小，说明方法对阈值选择**鲁棒**。
- **用户研究**：GazeME 在显著性对齐（68.8%）、语义对齐（64.7%）、视觉质量（65.6%）三项上均显著优于最强基线（p < 10⁻³）。
- **核心论断**：目标显著性最好被视为一种**相对属性**，双向标记提供了控制这种相对性的轻量接口，SPMA 帮助标记嵌入学到稳健的显著性知识。

## 7. 优点

- **任务创新**：首次提出"目标显著性提升"任务，定义了无需视觉先验、以自然语言控制视觉注意力的新交互范式，补充了现有"内容/位置/外观"控制之外的"注意力分布"控制。
- **方法轻量优雅**：仅优化 4 个标记 token 的嵌入，冻结全部骨干参数，训练仅 2 小时/单卡，成本极低且不损害预训练泛化能力。
- **关键洞见深刻**：抓住"显著性本质相对"这一核心，用双向标记（强调 + 抑制）显式建模相对关系。
- **SPMA 设计巧妙**：通过显著性分组、随机激活、一致性截断三步，既构造多样化训练样本形成隐式集成，又保证相对显著性排序不被破坏。
- **数据构建可扩展**：提出自动标注流水线（LLM 生成 → 分割 → 过滤 → AAM 打分 → NSS 适配），可规模化生成语言接地、对象级显著性的监督信号。
- **实验严谨**：捷径分析有效排除低层视觉伪影的混淆；用户研究采用随机顺序 + 二项检验；测试集刻意选取默认不显著对象，难度设置合理。
- **开源承诺**：将发布数据集与源代码，利于后续研究。

## 8. 不足与局限

- **依赖自动预测器的噪声**：训练数据依赖 AAM 做显著性估计、SAM3 做分割，两者均可能引入噪声与偏差；论文承认这一点，并建议未来用人类反馈迭代精炼，但需要复杂的标注流程与抗噪学习方案。
- **未建模空间交互与遮挡**：标记仅编码相对显著性，未显式建模对象间的空间关系或遮挡，在杂乱场景中性能可能受限；扩展到结构化或成对关系因其组合爆炸而困难。
- **仅限静态图像**：框架针对静态图像，扩展到视频需要时间一致的标记以在帧间保持显著性意图，超出当前范围。
- **数据与测试规模有限**：训练集 1,637 对、测试集 432 个任务，规模中等；场景多样性与对象类别覆盖可能不足。
- **用户研究覆盖有限**：仅 26 人、17 个任务，且只与单一最强基线对比，未涵盖全部基线，主观结论的泛化性有待更大规模验证。
- **基座模型依赖**：实验仅基于 FLUX.1-dev，未验证在其他文本到图像模型（如 SD 系列）上的可迁移性。
- **潜在应用风险**：显著性操控技术可能被用于误导性视觉传播（如广告夸大、注意力操纵），论文未讨论相关伦理与治理问题。
- **语义-显著性权衡**：CLIPScore 略低于基座模型，说明显著性提升与语义保真之间存在轻微折衷，虽在可接受范围内但仍需关注。
