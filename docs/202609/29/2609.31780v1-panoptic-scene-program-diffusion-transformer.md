## 摘要
现代文本到图像模型能生成高保真图像，但在处理需要实例身份、属性归属、计数、空间排序以及角色敏感关系的组合式提示时仍显吃力。我们提出全景场景程序扩散Transformer（PSP-DiT），一种扩散Transformer架构，将全景场景程序视为一等潜变量，而非外部控制信号或事后解析结果。PSP-DiT通过耦合的Transformer流对图像潜变量和场景程序潜变量进行联合去噪，同时利用全景定位和循环一致性目标，将对象实例、属性、关系和计数与生成图像中的视觉支撑关联起来。在匹配的训练和推理设置下，PSP-DiT在GenEval 2、SANEval-Simple、PSG-Score和DetailMaster上均优于强大的纯文本基线，在计数、属性绑定、角色敏感关系和长结构化提示方面提升最大。该方法保持图像质量，仅增加适度的推理开销，并且对不完美的场景程序保持稳健。

## Abstract
Modern text-to-image models produce high-fidelity images but still struggle with compositional prompts that require instance identity, attribute ownership, counting, spatial ordering, and role-sensitive relations. We introduce Panoptic Scene Program Diffusion Transformer (PSP-DiT), a diffusion-transformer architecture that treats a panoptic scene program as a first-class latent variable rather than an external control signal or post-hoc parse. PSP-DiT jointly denoises image latents and scene-program latents through coupled transformer streams, while panoptic grounding and cycle-consistency objectives tie object instances, attributes, relations, and counts to visual support in the generated image. Under matched training and inference settings, PSP-DiT improves over a strong flat-text baseline across GenEval 2, SANEval-Simple, PSG-Score, and DetailMaster, with the largest gains on counting, attribute binding, role-sensitive relations, and long structured prompts. The method preserves image quality, adds modest inference overhead, and remains robust to imperfect scene programs.

# PSP-DiT 论文结构化总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：文本到图像（T2I）生成已从潜在扩散、级联模型演进到扩散 Transformer 与整流流系统，视觉保真度、提示跟随与排版能力大幅提升（如 DALL-E 2、Imagen、SDXL、FLUX、SANA 等）。
- **核心问题**：科学瓶颈已从"低层真实感"转移到"组合忠实性"。现有系统在多实体、细节密集提示下仍会失败，具体表现为：
  - 实例身份混淆（重复类别无法区分）
  - 属性归属错误（颜色/材质挂到错误对象）
  - 计数不准
  - 空间/角色敏感关系错误（如"狗在猫后面"与"猫在狗后面"）
  - 长结构化提示退化
- **现有方法不足**：
  - 控制类方法（GLIGEN、ControlNet、Attend-and-Excite、BoxDiff）把结构当作**外部条件**；
  - 场景图方法通常将图生成与图像生成**分离**，或仅把图转成布局/语义作为引导；
  - 全景场景图研究主要用于**识别**，而非作为生成器中的一等潜变量。
- **整体含义**：作者主张真正缺失的是生成过程内部**显式的场景状态**，而非更强的文本编码器或更多数据。PSP-DiT 的目标是让对象、属性、关系、计数与视觉归属在**去噪轨迹中就被表示和精炼**，而不是事后再解析。

## 2. 方法论

### 2.1 核心思想
- 将**全景场景程序**（panoptic scene program）$s$ 建模为一等潜变量，联合建模 $p_\theta(z, s \mid y)$，而非传统的 $p_\theta(z \mid y)$。
- 场景程序 $s = (O, A, R, C, B)$：
  - $O = \{o_i\}_{i=1}^N$：实例索引对象
  - $A_i = \{a_{i\ell}\}$：实例挂载属性
  - $R = \{r_{ij}\}$：有序关系（保留主语–宾语角色）
  - $C$：基数/计数
  - $B$：场景上下文变量
- 与图/布局条件生成的关键区别：$s_t$ 是**被采样并联合精炼**的，而非固定不变。

### 2.2 耦合去噪架构
- 每个去噪步 $t$ 同时维护图像潜变量 $z_t$ 与场景程序潜变量 $s_t$，预测耦合去噪目标：
  $$(\hat{u}^z_t, \hat{u}^s_t) = f_\theta(z_t, s_t, y, t)$$
- 每块包含三种操作：
  - 流内自注意力：$S'_t = \text{ProgAttn}(S_t; y, t)$，$Z'_t = \text{ImgAttn}(Z_t; y, t)$
  - 双向跨流注意力：$\tilde{Z}_t = \text{CrossAttn}_{z\leftarrow s}(Z'_t, S'_t)$，$\tilde{S}_t = \text{CrossAttn}_{s\leftarrow z}(S'_t, Z'_t)$
  - 流特定头：$\hat{u}^z_t = h_z(\tilde{Z}_t, \tilde{S}_t)$，$\hat{u}^s_t = h_s(\tilde{S}_t, \tilde{Z}_t)$
- 图像 token 用当前场景状态更新，场景 token 用当前视觉状态更新。

### 2.3 全景接地与场景归属
- 接地头预测软归属场 $\hat{M}_t = g_\theta(Z_t, S_t)$，将图像 token 支撑分配给对象实例；
- 排序头预测 $\hat{D}_t = d_\theta(Z_t, S_t)$，建模粗粒度深度/遮挡结构；
- 这些变量强制重复对象保持分离、属性出现在正确实例区域、空间关系与几何一致。

### 2.4 训练目标
$$L = L_{img} + \lambda_{prog}L_{prog} + \lambda_{pan}L_{pan} + \lambda_{align}L_{align} + \lambda_{cycle}L_{cycle}$$
- $L_{img}$、$L_{prog}$：图像与程序去噪损失；
- $L_{pan} = L_{own}(\hat{M}, M^\star) + \lambda_D L_{depth}(\hat{D}, D^\star)$：全景接地损失；
- $L_{align} = \sum_i \ell_{align}(q_i, v_i)$：实例表征与支撑图像证据对齐；
- $L_{cycle} = \ell_{cycle}(\Pi(\hat{x}), s^\star)$：用冻结识别器 $\Pi$ 要求生成图像可恢复出目标场景结构。
- 默认权重：$\lambda_{prog}=1.0$，$\lambda_{pan}=1.0$，$\lambda_{align}=0.25$，$\lambda_{cycle}=0.5$，$\lambda_D=0.1$。

### 2.5 推理流程
- 给定提示 $y$，由提示到程序先验 $\Pi_{init}$ 初始化 $s_T$，图像潜变量 $z_T \sim \mathcal{N}(0,I)$；
- 联合采样 $(z_{t-1}, s_{t-1}) = \Phi_\theta(z_t, s_t, y, t)$，$t=T,\dots,1$；
- 最终图像由 $z_0$ 解码，场景解释由 $s_0$ 及归属/排序输出解码；
- **无需测试时搜索、重排序或外部优化**。

### 2.6 训练数据构造
- 三阶段：文本解析为候选结构 → 冻结全景分割/开放词汇接地图得到 $M^\star, D^\star$ → 协调文本与图像结构（移除无支撑对象、合并重复实例、仅保留两端均接地的关系）；
- 训练元组 $(x, y, s^\star, M^\star, D^\star)$；丢弃无前景实例或无支撑的场景；
- 上限 $N_{max}=16$ 对象实例、$R_{max}=32$ 关系 token、$C_{max}=8$ 计数 token、$B_{max}=8$ 上下文 token。

## 7. 优点

- **建模思路新颖**：把场景结构从"外部条件/事后解析"提升为"一等联合去噪潜变量"，概念上清晰且与现有控制方法、场景图方法形成明确区分。
- **架构设计合理**：双向跨流注意力 + 流特定头，使图像与场景状态互相修正，适合重复类别与有序关系。
- **接地与循环一致性**：归属场、排序头与循环识别器把结构忠实性绑定到**空间支撑**，而非仅依赖整体对齐指标，是方法论上的亮点。
- **实验规范性强**：统一评测管线、匹配基线（Ours-FlatText）、无 best-of-N、盲测人类偏好、bootstrap 置信区间、技能分解映射明确。
- **鲁棒性分析到位**：主动测试不完美程序，回答结构化方法常见的"依赖完美解析器"质疑。
- **规模与效率兼顾**：多规模、多分辨率验证，且报告了实际 H200 上的延迟/显存开销。
- **诚实度较高**：明确说明未发布代码/检查点，限制章节指出未扩展到视频，人类研究声明无报酬、无风险。

## 8. 不足与局限

- **应用范围受限**：仅针对文本到图像；未扩展到文本到视频，而视频中场景状态需跨帧时序一致，是明显的未覆盖场景。
- **无开源产物**：论文明确表示不发布代码、检查点或数据，复现门槛高，尤其依赖冻结解析器与识别器的具体实现。
- **外部对比公平性存疑**：FLUX.1-dev、SD3.5-Large 的分数来自统一内部管线复现，可能未反映这些模型在官方最优配置下的真实上限。
- **依赖外部冻结组件**：训练依赖文本到程序解析器、全景分割/接地图、循环识别器；这些组件本身的偏差会传导到训练目标，且论文未深入分析其误差传播。
- **场景程序表示有限**：上限 $N_{max}=16$、$R_{max}=32$、$C_{max}=8$、$B_{max}=8$，对极复杂场景（大量对象/关系）可能不足；属性/关系池化方式也未详述。
- **效率对比范围窄**：仅在匹配的自家 H200 设置下对比 FlatText，未与其他结构化方法（如 GLIGEN、ControlNet、场景图方法）做系统开销比较。
- **人类研究规模有限**：200 条提示、每对 3 位评分者、无报酬、无 IRB 正式审查，统计力与代表性有限；未说明评分者人口学构成。
- **定性评估主观**：图 2 与附录压力用例为作者选样，未报告失败案例或系统性错误模式分析。
