## 摘要
近年来，像素空间扩散模型的进展缩小了其与潜在空间扩散在图像质量上的差距，但其收敛仍然更慢，最终图像质量也落后。我们认为，一个关键原因是缺少显式的表征先验：与通常在紧凑且结构化的潜在空间中进行去噪的潜在扩散不同，像素扩散需要从原始RGB空间中同时学习有利于去噪的表征和像素生成。为了解决这个问题，我们提出了PixelDiT2，一种端到端的像素空间扩散模型，旨在将表征学习与像素生成解耦，同时不引入自编码器或潜在重建瓶颈。我们提出了表征锚定（representation grounding），利用冻结的预训练视觉基础模型在整个去噪过程中提供显式的逐块表征引导，使像素扩散Transformer能够更专注于像素生成。在ImageNet-256x256上，PixelDiT2在600个epoch后达到1.46的FID；在512x512分辨率下，PixelDiT2在680个epoch后达到1.48的FID。

## Abstract
Recent advances in pixel-space diffusion models have narrowed the image quality gap with latent-space diffusion, but still converge more slowly and lag behind in final image quality. We argue that a key reason is the lack of an explicit representation prior: unlike latent diffusion, which usually denoises in a compact and structured latent space, pixel diffusion needs to learn denoising-friendly representations and pixel generation simultaneously from raw RGB space. To address this problem, we propose PixelDiT2, an end-to-end pixel-space diffusion model designed to decouple representation learning from pixel generation without introducing an autoencoder or latent reconstruction bottleneck. We propose representation grounding that uses a frozen pretrained vision foundation model to provide explicit per-patch representation guidance throughout denoising, allowing the pixel diffusion transformer to focus more on pixel generation. On ImageNet-256x256, PixelDiT2 achieves an FID of 1.46 after 600 epochs; at 512x512 resolution, PixelDiT2 achieves an FID of 1.48 after 680 epochs.

- **背景**：像素空间扩散模型（pixel-space diffusion）近年来逐步缩小了与潜空间扩散（latent diffusion）在图像质量上的差距，但两个核心短板依旧存在：
  - **收敛更慢**：达到同等质量往往需要显著更大的训练预算（如 PixelDiT、JiT 需 600–850 epochs）。
  - **最终质量仍落后**：即便在充分训练后，FID 仍不及强潜空间模型（如 REPA-XL 1.29、RAE-XL 1.13）。
- **根因诊断（论文核心论点）**：像素扩散**缺乏显式的表征先验（explicit representation prior）**。
  - 潜空间扩散借助预训练自编码器，把语义结构与低层细节在去噪前就已"组织好"，潜空间更紧凑、更结构化。
  - 像素扩散直接从原始 RGB 出发，分布更松散；且现有方法（PixelDiT、JiT）**必须在同一网络中同时学习"利于去噪的表征"和"像素级生成"**，这种耦合使优化问题比潜空间扩散更难。
- **既有工作的定位与局限**：
  - RAE：用预训练视觉编码器替代 VAE 编码器，但仍在潜空间建模、需要训练解码器还原图像。
  - REPA / REPA-E：把预训练特征当作**训练期对齐目标**，采样时不评估编码器。
  - REG / Latent Forcing：把预训练特征作为**额外联合生成目标**（Latent Forcing 同时生成像素流与特征流），采样后丢弃特征流。
  - PixelDiT / DeCo：架构上分离语义建模与细节合成，但内部表征仍是扩散模型自身学出来的。
- **论文主张**：应让预训练视觉知识在**去噪全程直接可用**，且**不引入自编码器或潜重建瓶颈**，从而把"表征学习"与"像素生成"解耦。

## 2. 方法论

### 2.1 基础框架：像素空间 Rectified Flow

- 前向过程（线性插值）：
  - \(x_t = t\,x + (1-t)\,\varepsilon\)，\(v = x - \varepsilon\)，\(t\in[0,1]\)
  - \(x_1 = x\)（干净图），\(x_0 = \varepsilon\)（纯噪声）
- 网络输出 **x-prediction**：\(\hat{x}_\theta(x_t, t, y)\)，再由其推导速度预测：
  - \(\hat{v}_\theta = \dfrac{\hat{x}_\theta - x_t}{\max(1-t,\ \tau)}\)，其中 \(\tau = 0.05\) 防止 \(t\to1\) 时数值发散
- 损失（速度空间）：
  - \(\mathcal{L}_{\text{diff}} = \mathbb{E}_{x,\varepsilon,t}\,\|\hat{v}_\theta(x_t,t,y) - v\|_2^2\)
  - 除 \(t\approx1\) 处的裁剪外，该损失等价于对干净图像 \(x\) 施加 \(1/(1-t)^2\) 重加权
- 时间步采样：logit-normal 分布，\(\mu=-0.8,\ \sigma=0.8\)
- 骨干：单路径 **patch-level DiT**（类似 PixelDiT 的 patch 级通路），patch size \(p=16\)

### 2.2 表征锚定（Representation Grounding）三大组件

**（a）冻结的预训练视觉编码器 ℰ**

- 使用 DINOv3（256px 主实验为 S/16）作为表征先验，**训练与推理全程冻结**。
- 沿扩散轨迹对**当前噪声样本** \(x_t\) 编码：
  - \(\bar{g}_t = \mathcal{E}(x_t) \in \mathbb{R}^{B\times L\times d_\mathcal{E}}\)
  - \(L = (H/p)(W/p)\)，\(p=16\) 与扩散 Transformer 的 patch size 对齐。

**（b）时间步条件投影网络 \(P_g\)**

- 关键问题：ℰ 只在干净图上预训练，输入 \(x_t\)（\(t<1\)）后特征会**显著漂移**，且越接近噪声端漂移越大。
- 设计选择：**不微调编码器**，而是在编码器与扩散 Transformer 之间插入轻量投影网络：
  - \(g_t = P_g(\bar{g}_t,\ t) \in \mathbb{R}^{B\times L\times D}\)，\(D\) 为 DiT 隐藏维度。
  - 架构：单个 DiT 风格 Transformer block（宽度 \(D\)）——线性输入投影把 \(d_\mathcal{E}\to D\)，自注意力 + MLP，归一化层由时间步嵌入 \(e_t\) 经 AdaLN 调制，最后线性层输出 \(g_t\)。
- 作用：把"适配噪声分布"的压力全部限制在 \(P_g\) 内，保持预训练先验完整。

**（c）Spatial AdaLN 注入**

- \(g_t\) 与 DiT 的 patch token 共享同一 \(L\)-patch 网格（两侧均 16×16，patch 数与位置完全一致）。
- 直接将 \(g_t\) 作为扩散 Transformer 的 **spatial AdaLN 条件**，逐 patch、逐 block 地元素级调制其 Transformer block。
- 与 REPA 的本质区别：REPA 的预训练特征只是训练期辅助目标，采样时不评估编码器；PixelDiT2 的预训练表征**在推理时仍是去噪计算的一部分**，且通过逐 patch 条件保留空间结构。

### 2.3 CFG 下的 Dropout 设计

- 沿用 class dropout（\(p_{\text{drop}}=0.1\)），但**仅丢类别 token 不够**：grounding token 本身仍含类别判别信息，名义上的"无条件分支"仍能收到类别信号。
- 因此引入 **null-grounding 状态**：绕过 ℰ 与 \(P_g\)，回退为时间步嵌入与 null-class 嵌入的 broadcast；推理时 CFG 的无条件分支使用同一套 null grounding token，使训练/推理分布匹配。
- **延迟 grounding dropout（delayed schedule）**：从 epoch 160 恢复训练，之前只做 class dropout 并保留 grounding，之后才启用独立的 class + grounding dropout。灵感来自 GLIDE 在微调阶段才引入文本条件 dropout 的先例。
